- 本番サイト（V2.5）: https://c-a-p-engineer.github.io/kids-learning/ 
- V1旧版の全ソース: https://github.com/c-a-p-engineer/kids-learning/tree/archive/pre-dopagaki-20261026

## 特徴

- 1ゲーム5問で終了。自動連続プレイ・ガチャ・ペナルティなし。
- 不正解から再挑戦可能。ヒント利用と独力正答を区別。
- 経験値、成果画面、1/3/7/14日後の復習（間隔は初期設計値）。
- プレイヤー4枠。匿名・端末内のみの記録、保護者用のJSON書き出し。
- 動物の絵と名前が一致する「きつね・うさぎ・くま・ぱんだ」プロフィール（従来の4つの保存枠はそのまま）。
- ホーム・問題・結果の3曲BGM、タップ/正解/復習/クリア等の効果音、XPの星演出・クリア紙吹雪。
- 右上の⚙️オプションでBGMとSEを個別にON/OFFし、それぞれ0〜100%の音量を調整。初期BGM 75%・SE 65%。ブラウザの制限により最初のタップ後に再生。
- 音量の変更中もBGMを途切れさせず、端末内のプレイヤーごとに設定保存。静かなモード、OSの動き軽減にも対応。
- 問題の回答ボタンから小さな選択肢番号「1・2・3」を撤去し、答えだけを大きく表示。
- 音楽はWeb Audio APIで端末内合成し、外部音源のダウンロードや個人情報の送信なし。
- 既存V1のlocalStorageキーは削除・上書きしない。**V1データをV2へ変換する機能は未実装。**

## 開発

Node.js 20以上、TypeScript + Vite。新しい外部ゲームライブラリは導入していません。

~~~sh
npm ci
npm run test
npm run typecheck
./scripts/build.sh
~~~

- src/engine.ts — 全19ゲームの問題・採点・復習の純粋関数
- src/quest-main.ts — 共通クエスト進行、採点、保存、保護者画面
- src/activity-content.ts — 操作型4ゲームの教材と問題生成
- src/activity-ui.ts — 指なぞり・ブロック・文字列車・動作まねっこの入力と表示
- src/activity.css — 操作型4ゲームの専用スタイル
- src/game-audio.ts — 3つの場面BGMと短い効果音
- src/reward-effects.ts — 星・XP表示・紙吹雪、動き軽減対応
- src/game.css — ゲーム画面とレスポンシブUI
- scripts/check-games.mjs — 19ゲーム×5レベル×80例（約7,600問）と操作型ゲームの入力試験
- docs/ゲーム仕様V2.md — 現行仕様
- docs/renewal-2026/ — 研究根拠、旧資産、ゲームデザイン、設計計画

子どもの診断、IQ測定、学習効果の保証は行いません。旧ゲームの仕様と全実装は退避ブランチが正本です。


## V2.3: 進みやすい学習体験

- **正解後に自動進行**: 約1.75秒間、正解演出と説明を表示して次の問題へ（5問目は結果画面）。手動の「次」ボタンも残す。
- **15ゲーム×5レベル**: 各ゲームを2回クリアするごとに新レベルを解放。ホームに「レベル x/5」「つぎまで x/2」の進捗表示。問題もレベルに応じて難しくなる。
- **連打による当てずっぽう対策**: 誤答後は1〜2秒の短い入力待ちと、繰り返し誤答で考えるヒント。既得XP・レベルの取り消しなし。
- **5個単位の数表示**: 10なら5×2、20なら5×4の枠に分けてスマホでも見やすく表示。
- **カテゴリ別絞り込み**: かず・さんすう／ことば／かたち・きおく／せいかつ。
- **保護者用リセット**: 現在のキャラのV2学習記録だけ2段階確認後にリセット。設定・他キャラの記録・旧版の履歴は保全。
- 詳細: [レベル・UI仕様](docs/renewal-2026/04-level-progress-and-ux.md)。


## V2.4: 文字サイズを自分で選べる

- **右上 ⚙️ →「もじの おおきさ」** で80〜160%（10%刻み）に変更できます。標準は100%です。
- 問題文・回答・ヒント・ゲームカード・各設定画面などの文字が即時に変化します。見本を確認しながら調整可能。100%に戻すボタンあり。
- 端末内の**キャラクターごとに設定を保存**。V2の既存XP・クリア回数・復習データ・音量設定を維持。
- スマホでは「どうぶつ」「のりもの」などの長い回答を縦並びにし、サイズ拡大時に単語が途中で折れにくくしました。
- 文字サイズ130%以上の場合、正解の解説表示時間も比例して長くなります（100%で約1.75秒、160%で約2.8秒）。
- ブラウザ自体の文字拡大・ズームも引き続き利用できます。表示の確認は実機で行ってください。



## V2.5: 指で遊ぶ4つのゲーム

これまでの選択式とは別に、「ゆびで ひらがな」「かずの ブロックこうじょう」「ことば れっしゃ」「からだ まねっこ」を追加しました。ボタンのタップ・指なぞり・順番の組み立て・体の模倣で遊べます。保護者の介助なしでも可能な操作を優先しますが、個人差を尊重してください。

運動・なぞりは能力の採点や医療的な療育効果を測るものではなく練習として記録し、学力定着の正答率に混ぜません。軌跡や映像は保存・送信しません。カメラ・マイクも使用しません。座ってできる動作と休む選択肢があります。

[操作型4ゲームの仕様と安全上の制約](docs/renewal-2026/05-hands-on-games.md)。

## V2.6: スキルツリー・ステータス・毎日の学習記録

- 19ゲーム×5段階のスキルを一覧化。解放済みノードから好きなレベルを直接プレイ可能（未解放のレベルは選べない）。

- 既存のV2 save schema=2、V1記録は変更せず、同じ端末にのみ保存。保護者画面からの2段階リセットでは新しい日別履歴も対象になります。

## V2.7: 23種類のゲームとシンプルな操作

- 「おおきいのは？」は左右の数を直接タップ。別の「ひだり／みぎ」回答欄は置きません。
- 「せんと カーブ」で直線・横線・カーブ・波線・ぐるりをなぞってから、ひらがな練習へ進めます。
- ひらがなは画数（例：2かく、いま1かくめ）と青い書き始め番号を表示。「の」は1画のガイドを修正し、枠を大きく外れたら現在の1画だけやり直します。
- 新ゲーム：**点つなぎ・電車の迷路は指で線をなぞる**方式。**時計の針は直接つかんで回す**方式。なぞりは指やペンで線を直接引きます。時計の針はドラッグでき、針の補助操作は残します。
- 身体まねっこにリズム、左右、テンポを追加。座ったままの代替と休憩機能も維持。
- 保護者画面から保存済みのバックアップJSONを選択し、XP・クリア・学習日数の差分を確認後に復旧できます。
- コードの責務をsession.ts、storage.ts、trace-guides.ts、touch-content.ts、touch-ui.tsへ分けました。
- 仕様は docs/renewal-2026/07-simple-controls-and-tracing.md。E2Eはユーザー指示により延期。

## V2.8: 再挑戦で最新レベルに進む

- クエストをクリアした後の「もういちど」は、クリア結果によって新たに解放された最新レベルを開始します。
- 2回クリアでLV2、4回でLV3、6回でLV4、8回でLV5。まだ次が開いていなければ現在のレベルでもう一度遊べます。
- 結果画面のボタンは「レベルNへ すすむ」など、次に始まる難易度を明示します。スキルツリーからは引き続き任意の解放済みレベルを選べます。
- [残タスク・追加コンテンツ14案](docs/renewal-2026/08-next-roadmap-content.md) を優先順位付きで整理しました。

### 📳 バイブレーション（V2.8追加）
- 正解は短い1回、不正解は軽い2回、クリアは短い2回、新レベル開放は少し長めの段階的な振動でフィードバックします。ワークショップ途中の操作はごく短い1回です。
- **オプション → バイブ（しんどう）** からキャラクターごとにON/OFFと試し振動ができます。旧V2の保存履歴も失わずに設定を追加します。
- 振動非対応のブラウザ・端末では振動しません。「静かなモード」または端末側の「動きを減らす」設定では発火を抑えます。時計針やなぞりを動かしている間に連続振動は起こしません。

## V3.0 第2段階: 記録・復習・操作の整理

- 別タブで同じキャラの記録が変わったら古いデータの書き込みを停止し、読み直しボタンを案内（完全同時書き込みの排他ではなく、楽観的な検知）。
- 復習が3件以上溜まった場合は5問中最大3問を優先。直近の復習が難しいときだけ、スキルツリーに解放済みの一つ前のレベルで練習するボタンを表示。自動降格なし。
- 生活順序のカードと箱分けの石を直接タップして戻す。重複する操作説明を減らす。
- 紙吹雪の粒子数を抑えて表示負荷を減らす。保存形式・旧記録・28ゲーム・5問完結を維持。
- [仕様と未対応項目](docs/renewal-2026/11-v30-record-recall-touch-polish.md)。E2Eと実機操作確認は継続して延期。


## V3.1 原子的な保存・主操作の統一

- 同じキャラの複数タブからの同時保存を、Web Locksのキャラ別排他で直列化。保存前の古いスナップショット比較、別タブ更新の読み直し導線は継続。
- Web Locks API非対応環境では、安全を優先して書き込みを拒否。ゲーム開始時に保存できないことを案内。保存可否は実機で確認する。
- 設定画面・問題図・ヒントを独立モジュールへ。V2の保存形式と28ゲーム・5問区切りは不変。
- ブロック、ことば列車も「置いたものをタップして戻す」方式へ統一。重複説明と安全注意の画面占有を減らす。
- [V3.1仕様・28ゲーム監査表・次のタスク](docs/renewal-2026/12-v31-atomic-lock-ux-audit.md)。E2Eは引き続き延期。
