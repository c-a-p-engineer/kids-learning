# まなびクエスト — KIDS LEARNING V2

**年長向けの学習ゲーム10本を新規制作しました。** 数・言葉・図形・記憶・時計を、5問完結の短いクエストで学びます。

- V2プレビュー: https://c-a-p-engineer.github.io/kids-learning/feat-dopagaki-learning-redesign-20261026/
- 本番サイト: https://c-a-p-engineer.github.io/kids-learning/ （移行前はV1）
- V1旧版の全ソース: https://github.com/c-a-p-engineer/kids-learning/tree/archive/pre-dopagaki-20261026

## ゲーム

| # | ゲーム | 学ぶこと |
|---|---|---|
| 1 | かずシールド | 1〜10を数える |
| 2 | たしざんロケット | 10以内の足し算 |
| 3 | ひきざんスライム | 10以内の引き算 |
| 4 | かずのレール | 数の順番・規則 |
| 5 | おおきいのは？ | 大小比較 |
| 6 | はじめの もじ | ひらがなの語頭 |
| 7 | ことばトレジャー | 絵と言葉 |
| 8 | かたちパズル | 同じ形 |
| 9 | おぼえてカード | 見て覚えてから思い出す |
| 10 | じかんの とびら | 正時・30分の時計 |

## 特徴

- 1ゲーム5問で終了。自動連続プレイ・ガチャ・ペナルティなし。
- 不正解から再挑戦可能。ヒント利用と独力正答を区別。
- 経験値、成果画面、1/3/7/14日後の復習（間隔は初期設計値）。
- プレイヤー4枠。匿名・端末内のみの記録、保護者用のJSON書き出し。
- 音声読み上げボタン、初期OFFの効果音、静かなモード、動き軽減対応。
- 既存V1のlocalStorageキーは削除・上書きしない。**V1データをV2へ変換する機能は未実装。**

## 開発

Node.js 20以上、TypeScript + Vite。新しい外部ゲームライブラリは導入していません。

~~~sh
npm ci
npm run test
npm run typecheck
./scripts/build.sh
~~~

- src/engine.ts — 全10ゲームの問題・採点・復習の純粋関数
- src/quest-main.ts — ゲーム画面、進行、保存、保護者画面
- src/game.css — ゲーム画面とレスポンシブUI
- scripts/check-games.mjs — 800問と復習の回帰テスト
- docs/ゲーム仕様V2.md — 現行仕様
- docs/renewal-2026/ — 研究根拠、旧資産、ゲームデザイン、設計計画

子どもの診断、IQ測定、学習効果の保証は行いません。旧ゲームの仕様と全実装は退避ブランチが正本です。
