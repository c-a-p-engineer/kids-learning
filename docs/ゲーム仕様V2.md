# まなびクエスト V2 — 年長向け15ゲーム仕様

状態: 2026-10-26 実装済み・自動テスト済み。実児童での学習効果比較と端末実機評価は未実施。

## 目的と共通ループ

- 自分でゲームを選び、1セッション5問、正解の理由を確認して結果画面で終了する。
- 操作は3択または2択の大きなタップボタン。記憶は3枚を「おぼえた！」で隠した後に答える。
- 回答を間違えたときは同じ問題へ戻り、ヒントを見られる。誤答は次への進行を妨げず、正解で先へ。
- 経験値: 最初の一回・ヒント無しで正解なら10 XP、それ以外で正解なら5 XP。セッション完了だけでは追加XPを与えない。
- 記憶定着: 正答したitemを間隔を空けて復習。期限到来の旧問題を最大2問、新問題と合わせて5問。
- 復習: 独力正答で間隔が1→3→7→14日と伸びる。ヒントか誤答を挟んだ場合は1日へ戻る。
- 記録: プレイヤー1〜4に独立し、端末localStorageへ保存。ヒントあり/独力を区別。端末間共有なし。
- 終了は必ず明示的。5問終了後に自動ループせず、途中戻りでも報酬没収なし。

## ゲーム別の出題仕様

| ID | 目標 | 表示 | 正答の作り方 |
|---|---|---|---|
| count | 1〜10の数量認識 | 1〜10の点と盾 | 点の個数 |
| add | 10以内の加算 | a+b、2グループの点 | a+b。a=1..5、b=1..4 |
| subtract | 10以内の減算 | a-b、b個薄い点 | a-b。a=5..10、b=1..5 |
| sequence | 数の系列の見通し | a, a+step, ?, a+3step | step=1または2、?=a+2step |
| compare | 数の大小 | 左右の数と点 | 大きい側のひらがな（ひだり/みぎ） |
| kana | 語頭ひらがな | 絵文字と3文字 | 名称の最初の文字 |
| words | 絵とひらがなの対応 | 絵文字と3語 | 絵の名前 |
| shapes | 図形を見分ける | 1つの大きな形と3候補 | 同じ記号の形 |
| memory | 3枚の短期記憶 | 3枚提示 → 隠す → 3候補 | 提示された中央の絵 |
| clock | 時刻と針の対応 | 文字盤と長短針、3候補 | 1〜12時と30分 |
| bond | 10の分解 | a + ? = 10 | 10-a |
| pattern | 規則性 | 交互の絵柄 | 次の絵柄 |
| category | 身近な分類 | 絵とカテゴリ | どうぶつ・のりもの等 |
| odd | 視覚的比較 | 4つの絵のうち1つ違う | 違う位置（1〜4） |
| colors | 色の名前 | 色の円と選択肢 | 色の名前 |

### 特記事項

- 記憶ゲームの正解位置を中央固定から変更し、3つの提示位置全てを対象とする。
- ヒントでは直接答えを示さず、数え方・見方・手がかりを伝える。
- memoryは「絵を見る時間」をタイムアウトで強制しない。本人のボタン操作で回答へ移る。
- count/add/subtractは数量図と数式を併記。速度ではなく理解を中心にする。
- 時計は正時/半までで、5分刻み・分針読みは未実装。
- shapesは現時点で同形の選択。回転、鏡像、ドラッグ操作の訓練とは異なる。
- 文字と絵文字の対応は簡易的な幼児向け語彙。発達段階と読み上げ品質の実地評価は今後行う。
- 10コンテンツは独立した場面の問題を解くゲームとして動作し、長編RPGの共有マップや敵AIは未実装。

## UI / アクセシビリティ

- スマートフォン最小320px、標準360px、タブレット、PCのレスポンシブ表示。
- 主要ボタンは44px以上、focus-visibleが視覚的に分かる。
- 色のみで正答を判別しない。正解時は文字で理由を表示。
- 読み上げは明示ボタンで利用、端末が対応しないときも文字表示で続行。
- 静かなモード、BGM/効果音の個別ON/OFF、OS側reduced-motion対応。
- BGMはホーム/学習/結果の3曲をWeb Audio APIで端末内合成し、初回操作後に開始。保護者画面・非表示時は休止。
- 正解は星とXP表示、クエスト終了は紙吹雪。演出と採点は独立。失敗を責める刺激や無限報酬は使わない。
- 退出は常に可能で、ペナルティや報酬没収なし。

## 自動検証と残課題

~~~sh
npm ci
npm run test
npm run typecheck
./scripts/build.sh
~~~

自動: 10×80=1,200問の正答、選択肢、算術、復習予定、デッキ、期限。
機械試験の外: 児童の迷い、実際の認知負荷、発話や視覚提示、400%ズーム、一部端末の読み上げ、プレイヤー切替の実操作、画面連打。プレビューで手動Scenario QAが必要。

### 手動Scenario QA
1. 10枚の各カードからゲームを開き、最終問題まで解ける。
2. 3択に誤答→再答→ヒント→成功で独力扱いにならない。
3. 同じ回答ボタンを連打してもXPが2回増えない。
4. memoryで3枚→「おぼえた！」→3候補、答える間は元の絵が隠れている。
5. 1〜4のプレイヤーで経験値と復習予定が独立し、再読込後も残る。
6. 360px、768px、200%文字、キーボード、音OFF、OS reduced-motionで操作可能。
7. 新版で遊んでも旧V1のlocalStorageキーが変更されない。
8. 保護者画面のJSONエクスポートが当該プレイヤーだけを含む。
