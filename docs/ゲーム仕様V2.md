# まなびクエスト V2 — 年長向け19ゲーム仕様

状態: 2026-10-26 実装済み・自動テスト済み。実児童での学習効果比較と端末実機評価は未実施。

## 目的と共通ループ

- 自分でゲームを選び、1セッション5問、正解の理由を確認して結果画面で終了する。
- 既存15ゲームの基本操作は3択または2択のタップボタン。新4ゲームは指なぞり・数量組み立て・文字連結・身体模倣。記憶は3枚を「おぼえた！」で隠した後に答える。
- 回答を間違えたときは同じ問題へ戻り、ヒントを見られる。誤答は次への進行を妨げず、正解で先へ。
- 経験値: 最初の一回・ヒント無しで正解なら10 XP、それ以外で正解なら5 XP。セッション完了だけでは追加XPを与えない。
- 記憶定着: 正答したitemを間隔を空けて復習。期限到来の旧問題を最大2問、新問題と合わせて5問。
- 復習: 独力正答で間隔が1→3→7→14日と伸びる。ヒントか誤答を挟んだ場合は1日へ戻る。
- 記録: プレイヤー1〜4に独立し、端末localStorageへ保存。ヒントあり/独力を区別。端末間共有なし。
- 終了は必ず明示的。5問終了後に自動ループせず、途中戻りでも報酬没収なし。

## ゲーム別の出題仕様

| ID | 目標 | 表示 | 正答の作り方 |
|---|---|---|---|
| count | 1〜10の数量認識 | 1〜10の点と盾 | 点の個数 |
| add | 10以内の加算 | a+b、2グループの点 | a+b。a=1..5、b=1..4 |
| subtract | 10以内の減算 | a-b、b個薄い点 | a-b。a=5..10、b=1..5 |
| sequence | 数の系列の見通し | a, a+step, ?, a+3step | step=1または2、?=a+2step |
| compare | 数の大小 | 左右の数と点 | 大きい側のひらがな（ひだり/みぎ） |
| kana | 語頭ひらがな | 絵文字と3文字 | 名称の最初の文字 |
| words | 絵とひらがなの対応 | 絵文字と3語 | 絵の名前 |
| shapes | 図形を見分ける | 1つの大きな形と3候補 | 同じ記号の形 |
| memory | 3枚の短期記憶 | 3枚提示 → 隠す → 3候補 | 提示された中央の絵 |
| clock | 時刻と針の対応 | 文字盤と長短針、3候補 | 1〜12時と30分 |
| bond | 10の分解 | a + ? = 10 | 10-a |
| pattern | 規則性 | 交互の絵柄 | 次の絵柄 |
| category | 身近な分類 | 絵とカテゴリ | どうぶつ・のりもの等 |
| odd | 視覚的比較 | 4つの絵のうち1つ違う | 違う位置（1〜4） |
| colors | 色の名前 | 色の円と選択肢 | 色の名前 |
| trace | 指なぞり | 文字ガイド・描画面 | タッチでガイドに沿って動かす／点を番号順に押す |
| blocks | 数量合成 | 5枠フレームと機械 | +1/+5/-1操作で目標数量をつくる |
| train | 言葉の順序 | 絵とひらがな車両 | 文字を順に連結して単語を完成 |
| move | 模倣の身体遊び | 動作説明・椅子代替 | 本人の「やってみた」「おやすみ」 |


### 特記事項

- 記憶ゲームの正解位置を中央固定から変更し、3つの提示位置全てを対象とする。
- ヒントでは直接答えを示さず、数え方・見方・手がかりを伝える。
- memoryは「絵を見る時間」をタイムアウトで強制しない。本人のボタン操作で回答へ移る。
- count/add/subtractは数量図と数式を併記。速度ではなく理解を中心にする。
- 時計は正時/半までで、5分刻み・分針読みは未実装。
- shapesは現時点で同形の選択。回転、鏡像、ドラッグ操作の訓練とは異なる。
- 文字と絵文字の対応は簡易的な幼児向け語彙。発達段階と読み上げ品質の実地評価は今後行う。
- 19コンテンツは独立した学習あそびとして動作し、長編RPGの共有マップや敵AIは未実装。

## UI / アクセシビリティ

- スマートフォン最小320px、標準360px、タブレット、PCのレスポンシブ表示。
- 主要ボタンは44px以上、focus-visibleが視覚的に分かる。
- 色のみで正答を判別しない。正解時は文字で理由を表示。
- 読み上げは明示ボタンで利用、端末が対応しないときも文字表示で続行。
- 右上の⚙️オプションでBGM/効果音それぞれのON/OFF、音量0〜100%を調整・保存する。初期設定: BGM 75%、SE 65%。V2既存データには不足する音量設定だけ追加して引き継ぐ。
- 「きつね・うさぎ・くま・ぱんだ」の4つの匿名枠を使い、動物名と表示画像を一致させる。ホームの大きなキャラも現在の枠に連動。
- 回答ボタンでは数値・文字のみを大きく表示し、誤認を招く選択肢の序数は表示しない。3/5などの設問進捗と解答番号を混在させない。
- 静かなモード、BGM/効果音の個別ON/OFF、OS側reduced-motion対応。
- BGMはホーム/学習/結果の3曲をWeb Audio APIで端末内合成し、初回操作後に開始。保護者画面・非表示時は休止。
- 正解は星とXP表示、クエスト終了は紙吹雪。演出と採点は独立。失敗を責める刺激や無限報酬は使わない。
- 退出は常に可能で、ペナルティや報酬没収なし。

### 手動Scenario QA
1. 10枚の各カードからゲームを開き、最終問題まで解ける。
2. 3択に誤答→再答→ヒント→成功で独力扱いにならない。
3. 同じ回答ボタンを連打してもXPが2回増えない。
4. memoryで3枚→「おぼえた！」→3候補、答える間は元の絵が隠れている。
5. 1〜4のプレイヤーで経験値と復習予定が独立し、再読込後も残る。
6. 360px、768px、200%文字、キーボード、音OFF、OS reduced-motionで操作可能。
7. 新版で遊んでも旧V1のlocalStorageキーが変更されない。
8. 保護者画面のJSONエクスポートが当該プレイヤーだけを含む。

## V2.3 追加仕様

- 正解確定から約1.75秒で自動的に次の問題、最後は結果へ。途中退出・設定画面移動ではタイマー停止。
- クリア回数を用いるゲーム別5レベル。解放は2クリアごと、ホームで「レベル 1/5」「つぎまで 0/2」などを表示。
- 上位レベルでは数量上限、選択肢の数、時計の分単位、記憶枚数、規則の周期を増やす。
- 連続誤答を1〜2秒のクールダウンで抑制し、2回目から思考のヒントを表示。獲得済みXPは減らさない。
- 数のドットを5個ずつの枠で区切り、10個以上でもスマートフォンで視認しやすい表示。
- ゲームカテゴリ（全部／算数／ことば／図形・記憶／生活）のチップ絞り込み。
- 保護者画面のV2学習記録だけの二段階リセット。設定、旧版V1のキー、他のキャラは不変。
- 合計6,000問の問題生成・復習・レベル解放の自動テスト。
- 旧仕様の「次へボタン必須」「10本」「レベル無し」等はV2.3で置換。詳細は renewal-2026/04-level-progress-and-ux.md。


## V2.4 文字サイズ設定

- ホーム/問題中/結果画面共通の右上⚙️からオプションを開き、「もじの おおきさ」で80〜160%、10%刻みに設定。
- 初期100%。画面のプレビュー文字と実画面をリアルタイム変更。標準の100%へ戻すボタンを配置。
- 文字サイズは既存schema=2のsettings.textSizeへ保存。旧設定に存在しない場合は100%で補完し、NaNや上限外値を安全に正規化。
- 選択中のキャラごとに設定を保存し、別キャラの設定や学習データは不変。リセットの対象は学習記録だけで文字サイズ設定は維持する。
- HTMLルートの相対的なフォントサイズでremを調整。ブラウザの文字サイズ設定をなるべく尊重する。
- モバイル端末では3文字以上の長い回答を横3列で詰めずに縦並びに変更。特に「どうぶつ」「のりもの」「たべもの」が不自然に改行されないこと。
- 130%以上では一覧カードを1列にし、タップ可能な領域を維持する。
- 解説を読めるよう、自動次問の待ち時間は100%で約1.75秒、160%で約2.8秒に延長。変更後も手動の次ボタンは残す。
- 自動試験: 初期値、80/160%上限、10%刻みの丸め、既存データの欠損補完。実機での視覚的レイアウト確認は別途。



## V2.5 操作型ゲームの追加

4種の非選択式入力を追加。ゲームごとに5ステップで終了し、従来のXP・レベル・子ども別の保存記録を引き継ぎます。

特に `trace` と `move` の完了は学力・書字・運動能力の正誤を表しません。練習の参加を記録しますが復習の習得指標には混ぜません。座位代替・休憩と、キーボード/タップ代替を用意します。休憩だけで終えたセッションでは運動難易度は解放されません。カメラ/マイク/運動センサーは使用しません。

詳細・QA・参考研究: [05-hands-on-games.md](renewal-2026/05-hands-on-games.md)。

## V2.6 ステータスとスキルツリー

- ホームから2つの成長画面へ移動。ステータスは累計XP/クリア/解放スキル/復習待ち、今日の問題・独力・練習・クリア、7日サマリー、14日グラフ、30日の日別表。
- スキルツリーは19ゲームそれぞれLV1～LV5を連結ノードで表示し、2クリアごとの解放状況を既存`completed`から算出。解放済みノードはタップして該当レベルへ入れる。未解放は非操作の表示。
- 学力・療育達成度を示す称号ではなく、あくまで挑戦できる問題のレベル。
- 日誌の単位は端末ローカル日付。同じ学習の二重加点/二重記録を避ける。運動・書字なぞりの練習は独力正答の集計に混ぜず、休憩にもペナルティなし。
- 過去V2の累計学習記録は維持するが日付の分からない過去履歴は補完しない。日別記録はV2.6導入後から計測。
- 保護者リセットは日別記録にも適用し、4プロフィール分離、設定保全、旧V1キー不変。

## V2.7 直接タップ・運筆・バックアップ

- 大小比較は左右の数カードそのものを回答ボタンにする。別の「左・右」選択欄を作らない。
- ひらがな前に線・曲線なぞりの導入ゲームを追加する。
- ひらがなは画数・現在の画・書き始め番号を表示。ガイドから大きく外れたらその画だけやり直す。やり直し回数制限なし。
- 「の」は連続1画、こ・いは2画。正確な字形/筆圧/療育効果の測定とは扱わない。
- 点つなぎと電車迷路は**連続ポインター操作による線なぞりが主入力**。SVG描画で軌跡が見え、経路外や途中で指を離した場合はその試行をやり直す。番号の順押しは補助操作として残す。
- 時計は**短針・長針の直接ドラッグが主入力**。大きな透明ヒット領域と針先の丸い取っ手で操作しやすくし、端末に合わせた時刻単位へスナップする。＋／－は補助操作。
- 保護者のJSON復旧は保存枠、形式、サイズを検査し、差分プレビューと明示的な復元確認を求める。
- 既存学習履歴と4キャラの保存領域は不変。E2Eは未実施。
