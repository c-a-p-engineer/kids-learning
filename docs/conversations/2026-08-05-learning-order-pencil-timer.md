# 2026-08-05 学習順・えんぴつ練習修正

## 背景と目的

公開画面のカードがSTEP順に並んでおらず、えんぴつれんしゅうも固定5問だった。トップ画面をSTEP順へ固定し、えんぴつれんしゅうを時間内の達成数を記録する形式へ変更する。

## ユーザー要求の要約

- トップ画面をSTEP 1から順番に表示する
- えんぴつれんしゅうを5問制から、時間制限内に何個できるかの形式へ変更する

## 決定事項

### 学習カード

- 共通の学習経路を `src/learning-path.ts` に定義する
- カードへCSSの `order` を設定し、DOM初期化順にかかわらず表示順を固定する
- 2列では `1,2 / 3,4`、3列では `1,2,3 / 4,5,6` と行方向に並べる
- 各独立画面のSTEP表示も共通定義と一致させる

### えんぴつれんしゅう

- 全難易度を60秒制とする
- 正しくゴールした課題だけを完了数へ含める
- スキップは次の課題へ進むが、完了数へ含めない
- 自動ゴール判定、厳格採点、動画再生、WebM保存、既存保存キーを維持する
- 動画・厳格採点データの問題数は固定5問ではなく可変とする
- 既存履歴を読み込める後方互換を維持する

## 実施した変更

- 学習カードの固定表示順を追加
- えんぴつれんしゅうの60秒チャレンジ実装を追加
- 可変問題数の採点・履歴・動画再生を追加
- README、トップ画面、コンテンツ一覧、仕様書、学習セッション方針を更新

## 保留事項

- 60秒以外の時間を保護者が設定する機能
