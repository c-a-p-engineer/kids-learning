# 2026-09-05 道路横断ゲーム 走行音

## 日付

2026-09-05

## 背景と目的

`しんごうを わたれ！` のプレイ中に、車が動いていることを音でも感じられるようにする。単なるBGMではなく、道路上の車の存在感を補助する環境音として実装する。

## ユーザー要求の要約

- プレイ中に「ブーブー」のような車のエンジン音がほしい

## 決定事項

- 外部音源・追加依存は使わず Web Audio API で低いエンジン風の連続音を合成する
- ゲーム画面がアクティブで車が存在する間だけ鳴らす
- 車がプレイヤー付近へ近づくほど、音量と音程を少し上げる
- 車が多い場合は道路の交通量として音を少し厚くする
- LV5〜LV10の読み上げ中は自動的に環境音を約3割へ下げ、音声指示を優先する
- 衝突演出中、結果画面、レベル選択画面、ページ非表示時は環境音をフェードアウトする
- ブラウザの自動再生制限に従い、レベル選択・再挑戦・操作ボタン等のユーザー操作後にAudioContextを開始する
- 既存の成功音、衝突音、救急車の補助音は維持する

## 実施した変更

- `src/traffic-engine-sound.ts`: 道路走行中のエンジン風環境音を追加
- `src/contents/traffic-crossing.ts`: 走行音モジュールを読み込む

## 検証対象

- TypeScript型検査
- GitHub Pages向けビルド
- レベル選択後のプレイ中だけ走行音が鳴る
- 車が近づくと音の存在感が増す
- 読み上げ中に走行音が下がる
- 衝突時に走行音が下がり、衝突音を邪魔しない
- 結果・一覧・バックグラウンドで走行音が残らない
- pointer / keyboard のどちらから開始してもAudioContextが有効化できる

## 保留事項

- Pixel 8実機での音量・音質の体感調整
- 「もっとブーブー感」「もっと静かな道路音」など、子どもの反応を見た追加チューニング
