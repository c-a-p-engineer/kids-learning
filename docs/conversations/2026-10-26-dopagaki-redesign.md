# PROJECT DOPAGAKI / 全面学習ゲーム刷新

- 日付: 2026-10-26
- 状態: 一部確定（方向・退避は確定、各ゲームの新版ロジックと公開は未確定）

## 背景・目的

従来の11教材を、それぞれ独立した短時間ゲーム群から、学習定着と自発的参加を主目的とする統合ゲーム基盤へ全面刷新する。ゲームシーン、演出、アーキテクチャ、保存方式の再設計を認める。

## 要求の要約

- 最新の学習科学研究に基づき、勉強と報酬・達成感が結びつくゲームを構想する。
- 既存の全ゲームは、必要なら全面的に作り直す。
- アーキテクチャやフレームワークも適切なら変更する。
- 再制作前に既存ゲームを資料化し、旧資産と履歴を失わない。
- 幼児〜小学校低学年のスマホ/タブレット操作を中心に考える。

## 決定事項

- 旧版のコードを archive/pre-dopagaki-20261026 に退避する。
- 新設計は feat/dopagaki-learning-redesign-20261026 に分離する。master本番は検証完了まで変更しない。
- 学習課題とゲームの成功行為を統合し、分散学習・想起練習・適応難易度・達成フィードバックを中心にする。
- 実際の学習定着と、単なるゲームへの滞在・興奮・連打は別々に扱う。
- 強い成功演出は学習を支える範囲で使い、終了できなくなる要素は採用しない。
- 旧localStorageキーの削除、上書き、無確認の移行を禁止する。
- 保護者向け管理と、子ども向けの簡単な選択・回答導線を分ける。
- 各ゲームの再制作時はそれぞれの誤入力・ヒント・正答条件の実装に基づいて再検証する。

## 採用しなかった案

- ガチャ、高レア抽選、無限オートプレイ、ストリーク損失、児童ランキングなど、依存・滞在時間自体を最適化する仕組み。
- 旧保存記録を破棄して全員を初期化する案。
- 全ゲームを検証抜きでmasterへ一括投入する案。

## V2.1 強化（2026-10-26）

- 要求: GitHub上で「もっと楽しく、分かりやすく、ゲームへの意欲を上げる」。コンテンツ追加も許可。前発言で、プレイヤー1〜4の名前とBGM/SEの不十分さが指摘されていた。
- UI: 旧匿名IDの内部保存領域を変えず、表示を「ほしのこ🦊 / にじのこ🐰 / そらのこ🐻 / はなのこ🐼」に変更。誤操作しづらいマスコット選択カードへ。
- 音: 画面ごとの3つのWebAudio BGM（ホーム/問題/結果）と短い効果音を追加。ブラウザのユーザー操作後に開始。BGM/SEを独立設定し、非表示時は停止。音量を抑える。
- エフェクト: 正解・後日復習で星とXP表示、5問クリアで紙吹雪。静かモード / prefers-reduced-motionでは非表示。無限の報酬・ガチャ・ストリーク罰は採用しない。
- 教育上のバグ: 記憶ゲームの正解が常に中央の絵に固定されていた問題を修正。ヒントが答えそのものを表示する問題を修正し、思考の手掛かりに変更。
- 新ゲーム5本: 10の ともだち（数の合成）、つぎは なあに？（パターン）、なかま あつめ（分類）、ちがいを はっけん（視覚探索）、いろの まほう（色の認識）。合計15本へ。

- 保存: V2 schema=2のまま、settingsにbgmを追加。旧プレイヤー4枠と旧ゲームV1のlocalStorageキーは変更しない。
- 対象: feat/dopagaki-learning-redesign-20261026 / PR #25。master本番は公開切り替えまで旧版を維持。
- 制約: 画面を派手にすることと、学習への依存形成は別扱い。小区切りで自発的に止まれるゲームループを維持する。

## V2.2 実機画像からの改善（2026-10-26）

- 入力: ユーザーから実際の学習画面スクリーンショットと修正希望。BGMが小さい、SEも音量調整したい、オプションが欲しい、動物の絵に星の子等の抽象的名称は不一致、回答ボタン内の小さな1/2/3が解答値に見えて紛らわしい。
- 対応: BGMの合成音量の標準値を従来より増幅。SEは独立した音量スライダー、BGMとは別のON/OFFを追加。音量は0〜100%、既定 BGM 75%、SE 65%。設定はプレイヤーごとのschema=2内に保存し既存レコードを読み込む際は新フィールドだけ補完。
- オプション画面: 右上の⚙️から開く。音量を実際に聞きながら変更し、SE試聴、演出ON/OFFも集約する。画面遷移前の学習セッションを保持して戻る。
- キャラ: 🦊きつね、🐰うさぎ、🐻くま、🐼ぱんだ。ホームの大きなキャラも選択されたキャラに連動。匿名4人の保存スロット自体は従来通り。
- 解答UI: 選択肢の小さな1/2/3の序数表示を廃止し、回答値だけ大きく表示。読み上げ補助のaria-labelを補完。問題番号3/5との誤認も防止。
- BGM再生の改善: すべてのクリックでAudioContextを再unlocked→restartするロジックを修正。音量変更時はループタイマーを再生成しない。背景停止は引き続き維持。
- 限界: デバイス実際の音圧・OSミキサーはブラウザ外のため個体差あり。プレビューで親が音量を調整できるようにした。


## V2.3 ゲーム進行・レベル・安全なリセット（2026-10-26）

- 要望: 正解後の次問への自動移動。データリセット、ゲームごとに複数回クリアでレベル解放、解放進捗 x/xx、当てずっぽうの連打対策、数量シールドを5個単位にまとめる、学習カテゴリから遊びたいゲームにすぐ移動。
- 自動進行: 正解後、約1.75秒の解説と星演出を経て次問（最終問は結果画面）へ。手動進行も可能。複数クリックによる二重記録防止。退出・他ページ・バックグラウンド時はタイマーを破棄。
- レベル: 既存15ゲームにレベル1〜5を設定。2回クリアごとに一段階解放。カードにレベル x/5 と次まで x/2、進捗バーを表示。数、計算、時間、文字選択肢、記憶枚数、視覚探索など、各レベルの問題内容も増加。
- 旧学習履歴: level1のIDは維持し、level2以上にL2:などの接頭辞で独立IDを付与。localStorageの既存V2スキーマ2を維持し、問題読み込み時に難易度の名前空間を復元。旧V1キーにも手を触れない。
- 誤答: XPの没収やレベル降格ではなく約1.2〜2秒の入力抑制と、2回目以降に解法ヒント。誤答後の正解は既存通り独力初回正答とXPを区別。
- 数量: ドットを5個ずつの枠でまとめ、スマホでは縦並び。数量認識・加算・減算・大小比較に共通適用。
- カテゴリ: ぜんぶ、かず・さんすう、ことば、かたち・きおく、せいかつ。チップを横スクロール可能にし、表示カードのみ絞り込み。
- リセット: 保護者画面に当該キャラ1枠のV2学習記録を初期化する2段階確認。設定・他3キャラ・旧V1・エクスポート済みファイルは保全。保存エラー時は初期化しない。
- 自動検証: 15ゲーム×5レベル×80問=6,000問、クリア閾値、復習間隔、型検査、静的ビルド。
