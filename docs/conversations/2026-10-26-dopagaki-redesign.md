# PROJECT DOPAGAKI / 全面学習ゲーム刷新

- 日付: 2026-10-26
- 状態: 一部確定（方向・退避は確定、各ゲームの新版ロジックと公開は未確定）

## 背景・目的

従来の11教材を、それぞれ独立した短時間ゲーム群から、学習定着と自発的参加を主目的とする統合ゲーム基盤へ全面刷新する。ゲームシーン、演出、アーキテクチャ、保存方式の再設計を認める。

## 要求の要約

- 最新の学習科学研究に基づき、勉強と報酬・達成感が結びつくゲームを構想する。
- 既存の全ゲームは、必要なら全面的に作り直す。
- アーキテクチャやフレームワークも適切なら変更する。
- 再制作前に既存ゲームを資料化し、旧資産と履歴を失わない。
- 幼児〜小学校低学年のスマホ/タブレット操作を中心に考える。

## 決定事項

- 旧版のコードを archive/pre-dopagaki-20261026 に退避する。
- 新設計は feat/dopagaki-learning-redesign-20261026 に分離する。master本番は検証完了まで変更しない。
- 学習課題とゲームの成功行為を統合し、分散学習・想起練習・適応難易度・達成フィードバックを中心にする。
- 実際の学習定着と、単なるゲームへの滞在・興奮・連打は別々に扱う。
- 強い成功演出は学習を支える範囲で使い、終了できなくなる要素は採用しない。
- 旧localStorageキーの削除、上書き、無確認の移行を禁止する。
- 保護者向け管理と、子ども向けの簡単な選択・回答導線を分ける。
- 各ゲームの再制作時はそれぞれの誤入力・ヒント・正答条件の実装に基づいて再検証する。

## 採用しなかった案

- 単に正解エフェクトを激しくするだけのマイナーチェンジ。
- ガチャ、高レア抽選、無限オートプレイ、ストリーク損失、児童ランキングなど、依存・滞在時間自体を最適化する仕組み。
- 旧保存記録を破棄して全員を初期化する案。
- 全ゲームを検証抜きでmasterへ一括投入する案。

## 採用候補（まだ確定ではないもの）

- TypeScript+Viteを維持し、UIをPreactへ置換、学習ドメインを純粋関数へ分離する。

- 算数、ことば/記憶、図形/判断の3ワールド、身体遊びの独立広場。
- スキル復習間隔の初期候補1日→3日→7日→14日（科学的な最適値と断定しない）。

## 追加実装（同日・年長向け10ゲーム）

- ユーザーの追加指示: 「今のゲームを全て退避。年長レベルのものから10個くらい作る」
- 決定: 既存11本のコードと旧仕様書は旧版として退避。V2は現行機能から一新し、年長の数量、加減算、数列、比較、語頭、単語、図形、記憶、時計の10教材を実装する。
- 実装: src/engine.ts、src/quest-main.ts、src/game.css、src/index.htmlを中心とする静的学習アプリ。
- 共通仕様: 1ゲーム5問、誤答からの再挑戦、ヒント、読み上げ、静かモード、経験値、1/3/7/14日を初期値とする復習、匿名4プレイヤー。
- 保管: archive/pre-dopagaki-20261026 の旧コードは保持。旧V1ゲームのソース52ファイルをV2ブランチから撤去。旧ゲーム仕様11本と仕様書テンプレートは docs/legacy/ に移動。
- 旧localStorageキーは不変で、新アプリの保存キーは完全分離。端末内に残るV1データを新進捗へ自動移行していない。
- 採用技術: TypeScript/Vite継続、ゲームUIはVanilla DOMとCSS、追加UIフレームワーク・バックエンドなし。初期構想のPreactは採用保留。
- 自動テスト: 10ゲーム×80題と復習予定。npm run typecheck / scripts/build.sh。公開のプレビューはGitHub Actionsを使用。
- 未実装: 長編RPGワールド、物語連携、ボス、端末間同期、V1データimport、実機での児童利用評価、学習効果の比較。
- 現行仕様: docs/ゲーム仕様V2.md、docs/architecture.md、README.md。

## V2.1 強化（2026-10-26）

- 要求: GitHub上で「もっと楽しく、分かりやすく、ゲームへの意欲を上げる」。コンテンツ追加も許可。前発言で、プレイヤー1〜4の名前とBGM/SEの不十分さが指摘されていた。
- UI: 旧匿名IDの内部保存領域を変えず、表示を「ほしのこ🦊 / にじのこ🐰 / そらのこ🐻 / はなのこ🐼」に変更。誤操作しづらいマスコット選択カードへ。
- 音: 画面ごとの3つのWebAudio BGM（ホーム/問題/結果）と短い効果音を追加。ブラウザのユーザー操作後に開始。BGM/SEを独立設定し、非表示時は停止。音量を抑える。
- エフェクト: 正解・後日復習で星とXP表示、5問クリアで紙吹雪。静かモード / prefers-reduced-motionでは非表示。無限の報酬・ガチャ・ストリーク罰は採用しない。
- 教育上のバグ: 記憶ゲームの正解が常に中央の絵に固定されていた問題を修正。ヒントが答えそのものを表示する問題を修正し、思考の手掛かりに変更。
- 新ゲーム5本: 10の ともだち（数の合成）、つぎは なあに？（パターン）、なかま あつめ（分類）、ちがいを はっけん（視覚探索）、いろの まほう（色の認識）。合計15本へ。
- 自動検証: 15本×80件、計1,200問の出題、正解・重複・数の範囲・復習・新問題の具体的性質を確認。TypeScriptとGitHub Pages buildもCIで検証。
- 保存: V2 schema=2のまま、settingsにbgmを追加。旧プレイヤー4枠と旧ゲームV1のlocalStorageキーは変更しない。
- 対象: feat/dopagaki-learning-redesign-20261026 / PR #25。master本番は公開切り替えまで旧版を維持。
- 制約: 画面を派手にすることと、学習への依存形成は別扱い。小区切りで自発的に止まれるゲームループを維持する。
