# 2026-08-05 100そろばんの自由モード・問題形式・直接URL修正

## 要求

1. 自由に動かすモードを時間制限なしにする
2. 問題モードを、指定された数へ玉をそろえる問題だけに統一する
3. `/hundred-abacus` 直アクセス時に、かきとり画面ではなく100そろばんを表示する

## 決定事項

- 自由操作モードは時間制限なしとする
- 自動終了は行わない
- `おわる` ボタンを常時表示し、利用者が終了を選ぶ
- 自由操作では得点、ランキング、コンボを設けない
- 問題モードは10問を維持する
- 10問すべて、指定された数へ玉をそろえる形式とする
- `この数はいくつ？` と3択回答を削除する
- 直接URLでは、共通ルーターの初期描画後に100そろばん画面を再適用する

## 実装

- 自由モードのタイマー、残り時間バー、自動終了処理を削除
- 自由モードへ `0にもどす` と `おわる` を配置
- 終了時に実際の利用秒数を履歴へ保存
- 問題データを目標値だけの構造へ単純化
- 読み取り問題、選択肢、誤答処理を削除
- 初回のURL同期を `requestAnimationFrame` で遅延させ、共通ルーターによる画面上書きを回避

## 互換性

- 保存キー `hundred_abacus_v1_history` は変更しない
- 過去の自由モード履歴も読み込める
- 問題レベル、ヒント、自動正解、操作音、玉移動アニメーションは維持する
