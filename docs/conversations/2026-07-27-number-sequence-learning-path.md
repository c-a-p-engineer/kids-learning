# 2026-07-27 数の並びと学習経路

## 要求

- 時間制限なしモードは採用しない
- 子どもが区切りなく遊ばないよう、学習セッションに終了条件を設ける
- トップ一覧を上から順に進めれば学習段階が上がる構成にする
- 数の並びゲームを追加する
- 実装後に `master` へマージする

## 決定

- 反復クイズ型ゲームは時間制限必須とし、時間制限なしモードを設けない
- 数の並びは全難易度30秒固定とする
- 学習順は次の6段階とする
  1. 形を見る
  2. 見たものを覚える
  3. 数量を捉える
  4. 数の並びを理解する
  5. 数を比較する
  6. 文字や記号を書く
- トップカードに `STEP 1` から `STEP 6` を表示する

## 実装範囲

- `number-sequence` コンテンツ定義
- 3難易度、3択、30秒タイマー、得点、コンボ、履歴
- スマホ・タブレット対応
- 直接URL `/number-sequence`
- README、コンテンツ一覧、仕様書、学習セッション方針の更新

## 非採用

- 時間制限なしモード
- 自動で連続再挑戦する動作
- 終了条件のない自由プレイ
