# 2026-08-05 学習順・えんぴつ練習・100そろばん修正

## 背景と目的

公開画面のカードがSTEP順に並んでおらず、100そろばんも実物の玉の数え方と逆方向に見える状態だった。えんぴつれんしゅうは固定5問ではなく、時間内の達成数を記録する形式へ変更する。

## ユーザー要求の要約

- トップ画面をSTEP 1から順番に表示する
- えんぴつれんしゅうを5問制から、時間制限内に何個できるかの形式へ変更する
- 100そろばんで音を鳴らす
- 100そろばんの玉を5個・10個単位で色分けする
- 実物と同様に、左側の玉は数へ入れず、右側の玉だけを数える
- 添付された実物100そろばんの写真を表示設計の参考にする

## 決定事項

### 学習カード

- 共通の学習経路を `src/learning-path.ts` に定義する
- カードへCSSの `order` を設定し、DOM初期化順にかかわらず表示順を固定する
- 2列では `1,2 / 3,4`、3列では `1,2,3 / 4,5,6` と行方向に並べる
- 各独立画面のSTEP表示も共通定義と一致させる

### えんぴつれんしゅう

- 全難易度を60秒制とする
- 正しくゴールした課題だけを完了数へ含める
- スキップは次の課題へ進むが、完了数へ含めない
- 自動ゴール判定、厳格採点、動画再生、WebM保存、既存保存キーを維持する
- 動画・厳格採点データの問題数は固定5問ではなく可変とする
- 既存履歴を読み込める後方互換を維持する

### 100そろばん

- 0では全ての玉を左側へ表示する
- 右側へ寄った玉だけを現在値へ含める
- 未カウント群とカウント群の間に中央の空間を作る
- 5個ごとに赤・黄色を切り替える
- 段ごとに最初の色を切り替え、10個単位も識別しやすくする
- 通常移動、5の節目、10の節目で異なる音を鳴らす
- 保存形式と問題ロジックは変更しない

## 実施した変更

- 学習カードの固定表示順を追加
- えんぴつれんしゅうの60秒チャレンジ実装を追加
- 可変問題数の採点・履歴・動画再生を追加
- 100そろばんへ木枠、棒、左右配置、赤・黄色の玉、操作音を追加
- README、トップ画面、コンテンツ一覧、各仕様書、学習セッション方針を更新

## 保留事項

- 60秒以外の時間を保護者が設定する機能
- 100そろばんの色テーマ選択
- 実物そろばんと同じ玉の慣性・ドラッグ物理表現
