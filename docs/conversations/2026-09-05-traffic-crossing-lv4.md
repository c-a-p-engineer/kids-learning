# 2026-09-05 道路横断ゲームの拡張と整理

## 日付

2026-09-05

## 背景と目的

`しんごうを わたれ！` を、周囲を見る・待つ・止まる・再開する練習として実装し、実機プレイの反応を見ながら段階的に改善した。

一度LV10まで拡張したが、道路ゲームへ認知課題を集約しすぎず、道路横断として直感的なLV1〜6へ整理する方針へ変更した。より広い療育的な課題は、今後それぞれ独立した短いゲームとして追加する。

## ユーザー要求の要約

- 1〜4車線を段階化する
- 車速・車間をランダム化する
- 横断タイムとLV別ハイスコアを追加する
- 衝突時に音・振動・視覚フィードバックを出す
- `すすむ / ストップ` の文言差で画面が上下しないようにする
- 信号と救急車を追加する
- 救急車は音が聞こえなくても接近を視覚で判断できるようにする
- プレイ中にエンジン風の道路走行音を追加する
- 当初追加したLV7〜LV10は不要と判断し、LV1〜6へ整理する
- 最初からボタンを押し続けるだけでクリアできる場合があるため調整する
- 今後は道路ゲームを複雑化し続けるより、療育的な別コンテンツを増やしたい

## 現在の決定事項

### LV1〜LV6

- LV1: 1車線
- LV2: 2車線・逆方向
- LV3: 3車線・交互方向
- LV4: 4車線・交互方向
- LV5: 赤信号では移動不可。青でも通常の車確認が必要
- LV6: 救急車を周期出現させ、音に加えて方向付き `ちかづいてる / すぐそこ` HUDを表示する
- LV7〜LV10は選択画面・ゲーム進行から削除する

### 開始直後の押しっぱなし対策

- 開始から3.5秒以内に初めて移動する場合、最も手前の車線へ判断用車両を1台追加する
- 押しっぱなしなら横断位置で接触するタイミングへ初期位置と速度を合わせる
- 子どもが途中で止まれば回避可能にする
- 3.5秒以上安全確認して待った場合は判断用車両を追加せず、待つ行動を罰しない
- その後の交通は従来どおりランダム化する

### UI・フィードバック

- 上部ステータスは固定2段グリッドとし、文言差でプレイフィールドを動かさない
- 長い警告は道路内の固定HUDへ表示する
- 衝突時は失敗音、画面シェイク、`💥` 表示、対応環境の振動を併用する
- Vibration APIを唯一のフィードバックにしない
- プレイ中は車の近さ・交通量へ追従する低いエンジン風環境音を鳴らす
- 音声読み上げ中はエンジン音を下げ、結果・一覧・バックグラウンドでは停止する

### 保存互換

- 保存キー `traffic_crossing_v1_scores` は維持する
- 現行UIでは `one`〜`six` のLV1〜LV6だけを表示する
- 過去に保存された `seven`〜`ten` がある場合は、今後LV1〜6のスコアを保存しても値を削除しない
- 各現行レベル成功タイム最速5件のみ表示する

## 過去に実装したが現行から外したもの

一時的に以下をLV7〜LV10として実装した。

- バスによる死角
- 中央安全地帯での強制停止
- 指定マーク付き車を待つ課題
- 中央でのルールチェンジ

これらの考え方自体を否定したわけではない。道路横断ゲームへ集約するより、注意・抑制・切替などを目的とした別の療育ゲームへ分離する方が子どもにとってルールが明確と判断した。

## 実施した変更

- `src/traffic-crossing.ts`: LV1〜6へ整理、LV7〜10進行ロジックを削除、開始直後の押しっぱなし対策を追加、旧スコア互換を維持
- `src/contents/traffic-crossing.ts`: LV1〜6の説明へ更新
- `docs/しんごうをわたれ.md`: 現行LV1〜6仕様、開始直後の判断用車両、Scenario QAへ更新
- `docs/コンテンツ一覧.md`, `README.md`: 公開機能・保存内容を同期

## 検証対象

- TypeScript型検査
- GitHub Pages向けビルド
- LV1〜LV6だけが選択できること
- 開始直後から押しっぱなしにすると一度は停止判断が必要になること
- 3.5秒以上待ってから進む場合は判断用車両を追加しないこと
- 旧LV7〜10保存値を壊さないこと
- `すすむ / ストップ / まとう` 切替時に道路位置が動かないこと
- LV6で音なしでも救急車接近HUDが判断可能なこと
- 衝突時の音・視覚演出
- プレイ中のエンジン風環境音
- 360px縦、768px縦、キーボード、reduced-motion

## 今後の方向

- 道路ゲームはLV1〜6を中心に実プレイで調整する
- 注意、抑制、聴覚、切替、視覚探索、運動などの療育要素は、1ゲーム1ルールに近い独立コンテンツとして増やす
- 診断やIQ測定を目的とせず、家庭内で短時間に反復できる遊びとして設計する
