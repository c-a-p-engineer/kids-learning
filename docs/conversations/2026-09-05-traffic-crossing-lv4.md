# 2026-09-05 道路横断ゲーム LV4〜LV10・衝突フィードバック

## 日付

2026-09-05

## 背景と目的

`しんごうを わたれ！` を、車線数だけを増やすゲームから、見る・待つ・止まる・聞く・条件を保持する・途中で切り替えるまで段階的に練習できるゲームへ拡張する。衝突フィードバックは端末振動だけに依存せず、スマートフォンで確実に気づける複数経路を持たせる。

## ユーザー要求の要約

- 3車線と4車線を追加する
- 車に当たったときに音と振動を出す
- 車速・車間をランダム化し、横断タイムをLV別ハイスコアへ保存する
- 実機では衝突時の振動を感じられなかったため改善する
- `すすむ / ストップ` の文言差で改行が変わり、プレイ画面が上下する問題を直す
- LV5〜LV10まで実装する
- 救急車は音が聞こえない場合でも、近づいていることを視覚的に判断できるようにする

## 決定事項

### LV1〜LV4

- LV1: 1車線
- LV2: 2車線・逆方向
- LV3: 3車線・交互方向
- LV4: 4車線・交互方向
- 車速・車間のランダム化は各車線で独立して維持する

### LV5〜LV10

- LV5: 赤信号では移動不可。青でも通常の車確認が必要
- LV6: 救急車を周期出現させ、音に加えて方向付き `ちかづいてる / すぐそこ` HUDを必須にする
- LV7: 大きいバスで隣車線を一時的に隠し、死角では待つ判断を促す
- LV8: 中央安全地帯で自動停止し、再確認してから後半へ進む
- LV9: 音声＋文字で指定されたマーク付き車が通るまで移動をブロックする
- LV10: 前半条件達成後、中央で異なるマークへルール変更し、再び条件達成してから進む

### UI安定化

- 上部ステータスを固定2段グリッドにし、状態文言の長さでプレイフィールドを動かさない
- `よくみよう / すすむ / ストップ / まとう` は短い固定領域で表示する
- 長い警告やミッション文は道路内の絶対配置HUDへ分離する

### 衝突フィードバック

- Vibration APIを唯一のフィードバックにしない
- 失敗音を強める
- 約0.5秒の画面シェイク、`💥` オーバーレイ、プレイヤーヒット表現を追加する
- 結果画面への遷移を約0.56秒遅らせ、衝突演出を視認できるようにする
- 対応環境では従来より長い振動パターンを要求する
- `prefers-reduced-motion` ではシェイクを止め、静的な衝突表示を残す
- 血液・負傷表現は使用しない

### 保存互換

- 保存キー `traffic_crossing_v1_scores` は維持する
- `one`〜`ten` をLV1〜LV10として使用する
- 旧LV1〜LV4の保存データをそのまま読み、未存在のLV5〜10を空配列として扱う
- 各レベル成功タイム最速5件のみ保持する
