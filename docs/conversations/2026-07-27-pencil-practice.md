# 2026-07-27 えんぴつれんしゅう

## 要求

- 鉛筆の練習に相当するコンテンツを追加する
- 文字を書く前の線なぞり、点や道をたどる練習を扱う
- 終了条件のない遊びにはしない
- 実装、仕様更新、検証を行い `master` へマージする

## 決定

- コンテンツ名は「えんぴつれんしゅう」とする
- contentIdは `pencil-practice` とする
- 学習経路のSTEP 7へ配置し、かきとりマスターをSTEP 8へ移動する
- 1セット5問で終了する
- 書字前課題のため時間制限ではなく問題数を終了条件とする
- やさしい・ふつう・むずかしいの3段階を用意する
- 始点 `①` と終点 `🏁` を視覚的に表示する
- 線の通過範囲、始点、終点から参考スコアを計算する
- 点数は診断・療育評価に使用せず、低得点でも責める表現を使用しない
- 保存するのは結果だけとし、描画した線そのものは保存しない

## 学習経路

1. 形を見る
2. 見たものを覚える
3. 数量を捉える
4. 数の並びを理解する
5. 数を比較する
6. 時計を読む
7. 線を運ぶ
8. 文字や記号を書く

## 実装範囲

- Pointer Eventsによる指・タッチペン・マウス入力
- Canvasによるお手本と描画線の表示
- 3難易度、各5問
- やりなおし、完了、結果、履歴
- スマートフォン・タブレット対応
- `/pencil-practice` の直接URL
- README、トップ画面、コンテンツ一覧、個別仕様書の更新

## 非採用

- 終了条件のない自由描画
- 自動で次のセットを開始する動作
- 鉛筆の持ち方、姿勢、筆圧の自動判定
- 描画線の長期保存
