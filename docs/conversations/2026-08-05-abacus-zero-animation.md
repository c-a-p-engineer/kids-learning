# 2026-08-05 100そろばんの0操作と移動表現

## 背景

実物風の左右配置へ変更した後、現在値が1のときに右側の玉を左へ戻して0にする操作ができなかった。また、値の変更時に玉が再描画されるため、左右へ動いたことが視覚的に分かりにくかった。

## 決定事項

- 左側にある未カウントの玉を選ぶと、その玉から右端までを右側へ移して数を増やす
- 右側にあるカウント済みの玉を選ぶと、その玉を含む左側の玉を戻して数を減らす
- 値が1のとき、右側の1個を選ぶと0へ戻す
- 玉の位置は左右別のCSSプロパティではなく、単一の横位置で管理する
- 再描画後も変更前の値を保持し、Web Animations APIで変更前位置から変更後位置へ移動させる
- 移動時間は約360ミリ秒とする
- 複数の玉が動く場合は短い時間差を付ける
- 移動中の玉は一時的に拡大・発光させる
- 動きを減らす設定ではアニメーションを停止する

## 受け入れ条件

- [ ] 1から0へ玉のタップで変更できる
- [ ] 2以上から任意の小さい値へ変更できる
- [ ] 0へ戻ると全ての玉が左側へ移動する
- [ ] 値が変わると対象の玉が左右へ滑って移動する
- [ ] 複数個の移動を目で追える
- [ ] タップ、ドラッグ、キーボードの既存操作を維持する
- [ ] `prefers-reduced-motion` では即時表示する
