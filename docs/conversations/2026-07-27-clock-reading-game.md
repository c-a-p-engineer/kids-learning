# 2026-07-27 時計読みゲーム

## 要求

- 時計を学習するコンテンツを追加する
- 実装後に `master` へマージする
- 既存方針どおり、時間制限なしモードは設けない
- 学習経路が上から順に進む構造を維持する

## 決定

- コンテンツ名は「とけいを よもう」とする
- 学習経路のSTEP 6へ配置し、書字をSTEP 7へ移動する
- 全レベル30秒固定とする
- やさしいは正時、ふつうは正時と30分、むずかしいは5分単位とする
- アナログ時計をSVGで描画し、時針は分に応じて連続的に動かす
- 回答は3択とし、スコア、コンボ、履歴を保存する

## 学習経路

1. 形を見る
2. 見たものを覚える
3. 数量を捉える
4. 数の並びを理解する
5. 数を比較する
6. 時計を読む
7. 文字や記号を書く

## 追加対応

前回追加した「かずの ならび」の実装ファイルがHTMLの実行エントリから読み込まれていなかったため、共通UIのエントリから読み込むよう修正する。

## 非採用

- 時間制限なしモード
- 秒針を使う問題
- 午前・午後の問題
- 結果画面からの自動再開
