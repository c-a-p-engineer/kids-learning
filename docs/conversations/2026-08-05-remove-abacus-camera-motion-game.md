# 2026-08-05 100そろばん削除とカメラ運動ゲーム検討

## 背景と目的

100そろばんはタッチ操作の改善を重ねたが、教材として継続せず削除する。代わりに、カメラ映像上のオブジェクトへ手や体を当てて遊ぶ、子ども向けの運動あそびを検討する。

## ユーザー要求の要約

- 100そろばんに関する実装・表示・文書を全て削除する
- カメラを使い、子どもが身体を動かして楽しめるゲームにする
- 例として、画面上へ出現したオブジェクトを手で破壊する遊びを想定する

## 決定事項

- `hundred-abacus` を公開コンテンツから削除する
- 関連する実装、スタイル、仕様書、過去のそろばん会話記録を削除する
- 学習経路を8コンテンツへ戻し、後続STEPを繰り上げる
- カメラ運動ゲームは現時点では未実装の提案とする
- 初期候補は、手の位置と速度で画面上のオブジェクトを壊す「うごいてブレイク」とする
- カメラ映像を保存・送信せず、端末内だけで処理する方針とする
- 医療・療育効果を判定する機能にはしない

## 実施した変更

- 100そろばんのTypeScript、SCSS、コンテンツ定義を削除
- 100そろばん仕様書と関連会話記録を削除
- `src/contents/index.ts` と `src/learning-path.ts` を8コンテンツへ更新
- README、ドキュメント索引、トップ画面仕様、コンテンツ一覧、学習セッション方針を更新
- `docs/proposals/カメラ運動ゲーム案.md` を追加

## 保留事項

- カメラ運動ゲームの正式名称とcontentId
- Pose LandmarkerとHand Landmarkerの最終選定
- 初版を上半身だけにするか、全身対応にするか
- 対象端末と最低性能
- オブジェクトのテーマ、キャラクター、演出
- 実装開始時期
