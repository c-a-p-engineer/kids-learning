# 2026-09-04 きいて！ミッション拡張・道路横断ゲーム追加

## 日付

2026-09-04

## 背景と目的

音声指示を聞く練習を、単純な1〜3個の保持だけでなく「待つ」「押さない」「条件で判断する」まで段階化する。また、視覚的に周囲を見ながら動作を開始・停止する短時間ゲームを追加し、反復して遊びたくなるゲーム性も持たせる。

## ユーザー要求の要約

- `きいて！ミッション` をLV1〜6まで実装する
- 道路横断・信号渡りをモチーフにしたゲームをLV2まで実装する
- 道路ゲームは左右から車が来る
- ボタンを押している間だけ移動する
- 車と衝突したらそのプレイを終了する
- 車絵文字の向きと実際の進行方向を一致させる
- 横断に何秒かかったか表示し、ハイスコアとして残せるようにする
- 車の速度・出現間隔をランダム化し、毎回同じ攻略にならないようにする

## 決定事項

### きいて！ミッション

- LV1: 1個指示 / 4択
- LV2: 2個順序 / 6択
- LV3: 3個順序 / 8択
- LV4: 音声で対象を聞き、ランダムな合図音まで待つ
- LV5: `Aは押さない、Bを押す` のNo-Go型指示
- LV6: `あめならA、はれならB` を聞き、後から表示される条件で選ぶ
- LV6のA/Bは毎問ランダムにし、条件表示だけの暗記では解けないようにする
- 全レベル5ミッション、時間制限なしを維持する
- 誤タップ・先行タップで即終了せず、正しい課題へ戻る経験を重視する
- 既存保存キー `listening_mission_v1_history` を維持する
- 旧 `one` / `two` / `three` 履歴と新 `wait` / `nogo` / `condition` を同居させる
- 記録は診断・IQ評価に使用しない

### しんごうを わたれ！

- contentId: `traffic-crossing`
- 学習経路STEP 2へ置く
- LV1: 1車線、一方向の車
- LV2: 2車線、左右逆方向の車
- `おして すすむ` を押している間だけ前進する
- 指を離す、ボタン領域から外れると停止する
- 車との衝突で即終了する
- ゴール到達で成功する
- 衝突表現は血液・負傷表現を使わず `⚠️` と短い音にする
- 車絵文字は端末上の標準向きを前提に、右方向へ進む車だけ水平反転して進行方向と見た目を一致させる
- プレイ開始から終了までを0.1秒単位で計測する
- 成功タイムのみ `traffic_crossing_v1_scores` へ保存し、LV1/LV2別に最速5件を保持する
- 衝突したプレイはランキングへ登録しない
- 車種は `🚗 / 🚕 / 🚙` からランダムに選ぶ
- 車ごとに速度を設定範囲内でランダム化する
- 次の車の出現間隔もランダム化し、一定確率で短い連続車・長めの安全時間を作る
- プレイヤー速度と当たり判定サイズはランダム化しない
- ランダム性があるため、横断タイムは能力測定ではなくゲームのハイスコアとして扱う
- 実際の交通ルール判定・安全保証の教材とはせず、注意・停止・再開のゲームとして扱う
