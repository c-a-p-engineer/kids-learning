# コンテンツ一覧

現在公開されている学習コンテンツと、実装・仕様書・保存データの対応をまとめます。

## 一覧

| contentId | コンテンツ | 分野 | 主な対象 | 主な操作 | 仕様書 |
|---|---|---|---|---|---|
| `kakitori` | かきとりマスター | 国語・書字 | 文字を書く練習をする子ども | 指・ペンで描く、課題を選ぶ | [かきとりマスター.md](かきとりマスター.md) |
| `dotburst` | ドットバースト | 算数・数量認識 | 数をまとまりで捉える練習をする子ども | 表示数を選ぶ | [ドットバースト.md](ドットバースト.md) |
| `flashcard` | えもじフラッシュ | 記憶・ことば | 見たものを覚えて答える練習をする子ども | 絵文字を見る、2択で答える | [えもじフラッシュ.md](えもじフラッシュ.md) |
| `larger-number` | どっちが大きい？ | 算数・大小比較 | 数の大小を判断する練習をする子ども | 大きい数のカードを選ぶ | [どっちが大きい？.md](どっちが大きい？.md) |
| `fit-shape` | ぴったりシェイプ | 図形・空間認識 | 同じ形を見分ける練習をする子ども | 図形をドラッグして重ねる | [ぴったりシェイプ.md](ぴったりシェイプ.md) |

## 保存データ

各コンテンツの記録はブラウザの `localStorage` に保存されます。サーバーへのアカウント登録や同期は現在ありません。

| コンテンツ | 主な保存内容 |
|---|---|
| かきとりマスター | 課題、練習履歴、画像、ストローク情報 |
| ドットバースト | 難易度別スコア履歴 |
| えもじフラッシュ | レベル、正答率、出題絵文字、履歴 |
| どっちが大きい？ | レベル、スコア、正解数、履歴 |
| ぴったりシェイプ | 難易度、スコア、履歴 |

保存キーと保持件数は、各コンテンツ仕様書を正とします。

## 共通受け入れ条件

- [ ] ポータルから1回の選択で開始画面へ移動できる
- [ ] 360px程度のスマホ縦幅で主要操作が隠れない
- [ ] 768px以上のタブレットでカードや操作領域が過度に引き伸ばされない
- [ ] 主要ボタンが指で押しやすい
- [ ] 色だけに依存せず状態を判別できる
- [ ] 画面離脱後も既存の保存記録が維持される
- [ ] 直接URLから対象コンテンツを開ける
