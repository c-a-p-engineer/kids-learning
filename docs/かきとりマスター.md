# かきとりマスター 仕様書

## 1. 概要
- 目的: 文字の反復練習、書き順確認、記録保存
- 対象ユーザー: ひらがな/漢字の書字練習者
- 関連コンテンツID: kakitori

## 2. 画面構成
- 画面名: ミッション一覧 / 練習プレイ / 保護者モード
- 主なUI要素:
  - ミッションカード（開始・削除）
  - キャンバス（ガイド/描画）
  - 進捗表示（現在文字数/総文字数 XX% + プログレスバー）
  - 書き順お手本（再生）
  - アクション（できた/読む/やりなおす/やめる）
- レイアウト方針（スマホ縦優先）:
  - キャンバス固定比率、操作ボタンは下部縦積み

## 3. 操作フロー
1. ミッション選択
2. 文字ごとに書く -> できた
3. 最終文字・最終周回完了でホームへ戻る

## 4. 機能仕様
- 入力: タッチ/ポインタ描画、各種ボタン操作
- 出力: 練習履歴画像/動画、進捗表示、完了演出
- 状態遷移: home -> play -> home（完了/中断）
- バリデーション/制約:
  - ミッション追加: 文字必須、回数1〜20
  - 進捗: 総文字数 = 文字数 x 回数

## 5. データ仕様
- 使用ストレージキー: `missions`, `history`（STORAGE_KEYS経由）
- 保存項目: ミッション定義、履歴（missionId/char/img/stroke/time）
- 保持件数/削除ポリシー:
  - 履歴は古い10件削除機能あり
  - ミッション削除時に紐づく履歴も削除

## 6. 表示・演出仕様
- 文言: 「できた！」「やりなおす」「書き順のお手本」等
- 色/テーマ連動: 全体テーマ変数に追従
- アニメーション/SE: 完了スタンプ表示、読み上げ/トーン再生

## 7. 例外・エラー時挙動
- データなし時: 初期ミッション表示
- 通信失敗時: 書き順SVG取得失敗時にエラーメッセージ表示
- 非対応端末時: MediaRecorder未対応時は動画保存不可

## 8. 受け入れ条件（Yes/No）
- [ ] 描画と消去が正常に動作する
- [ ] 進捗テキストとバーが総文字数基準で一致する
- [ ] ミッション削除で関連履歴も削除される
- [ ] 書き順お手本の再読み込み/再生ができる
