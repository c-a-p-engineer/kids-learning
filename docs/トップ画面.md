# トップ画面 仕様書

## 1. 概要
- 目的: 学習コンテンツを一覧表示し、目的のコンテンツへ最短導線で遷移する
- 対象ユーザー: 幼児〜小学生と保護者
- 関連コンテンツID: portal

## 2. 画面構成
- 画面名: コンテンツ一覧（ポータル）
- 主なUI要素:
  - タイトル（まなびのライブラリ）
  - テーマ切替（暖色/寒色/ファンシー/サイバー）
  - 検索入力
  - カテゴリフィルター（ぜんぶ/こくご/さんすう/きおく）
  - コンテンツカード一覧
  - 空状態メッセージ
- レイアウト方針（スマホ縦優先）:
  - ヘッダー領域はsticky
  - カードはモバイル1列、640px以上で2列

## 3. 操作フロー
1. テーマを選択
2. 必要に応じて検索語を入力、カテゴリを選択
3. カードをタップして対象コンテンツへ遷移

## 4. 機能仕様
- 入力: テーマボタン、検索文字列、カテゴリフィルタ、カード選択
- 出力: カード絞り込み結果、該当なしメッセージ、画面遷移
- 状態遷移: portal -> home/play/parent（選択コンテンツに応じる）
- バリデーション/制約:
  - 検索は小文字比較でタイトル/説明/タグを対象
  - フィルター値は all/language/math/memory のみ有効

## 5. データ仕様
- 使用ストレージキー: `ui_theme_v1`
- 保存項目: テーマ値（warm/cool/fancy/cyber）
- 保持件数/削除ポリシー: 単一値を上書き保存

## 6. 表示・演出仕様
- 文言: 「まなびのライブラリ」「なにであそぶ？」など
- 色/テーマ連動: bodyのCSS変数をテーマ別に切替
- アニメーション/SE: カード押下時スケール変化

## 7. 例外・エラー時挙動
- データなし時: 空状態メッセージを表示
- 通信失敗時: 該当なし（トップ画面は外部通信なし）
- 非対応端末時: レイアウトは1列表示で継続

## 8. 受け入れ条件（Yes/No）
- [ ] テーマ切替が即時反映される
- [ ] 検索とカテゴリのAND条件で絞り込みできる
- [ ] 該当カード0件時に空状態が表示される
- [ ] カードタップで対応コンテンツへ遷移できる
