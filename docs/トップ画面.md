# トップ画面（V2）

## 画面構造

1. ロゴ、経験値、静かモード、効果音切替、BGM切替
2. 今日の冒険案内、完了数
3. きつね・うさぎ・くま・ぱんだの4つの匿名キャラ枠
4. 15ゲームのカード（ゲーム名、目的、復習待ち、クリア回数）
5. 終了方法とデータ保存方法の案内、保護者画面リンク

## 操作

- すきなカードから5問クエストへ。強制順番なし。
- 不正解時も回答可能、ヒントを使用できる。
- 最終問題の後は自動再開せず、別ゲームか再挑戦を明示選択。
- 保護者画面へは結果・記録一覧とJSON書き出しを分離。
- 音声の初期OFF、静かモード、文字ズーム、フォーカス可視化に対応。

旧版の10STEPポータルは現行画面には置かず、V1アーカイブで参照する。
