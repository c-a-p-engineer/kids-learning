# トップ画面 仕様書

## 1. 概要

- 目的: 学習コンテンツを一覧表示し、子どもが迷わず目的のコンテンツを開始できるようにする
- 対象ユーザー: 幼児〜小学生と保護者
- 関連コンテンツID: `portal`
- 公開URL: `/`

## 2. 画面構成

- 画面名: まなびのライブラリ
- 主なUI要素:
  - 補助見出し「あそんで まなぼう」
  - タイトル「まなびのライブラリ」
  - コンテンツ件数
  - 折りたたみ式の色設定
  - 検索入力
  - カテゴリフィルター（ぜんぶ / こくご / さんすう / きおく / ずけい）
  - コンテンツカード一覧
  - 該当なしメッセージ
  - ブラウザ保存の案内
- コンテンツカード:
  - かきとりマスター
  - ドットバースト
  - えもじフラッシュ
  - どっちが大きい？
  - ぴったりシェイプ

## 3. レスポンシブ方針

### スマートフォン

- 1列表示
- ヘッダーはスクロール中も検索・カテゴリへ戻りやすいsticky表示
- 横スクロールはカテゴリボタンなどの補助操作だけに限定
- セーフエリアを考慮する

### タブレット

- 2列表示
- 検索とカテゴリを横並びにする
- 学習カードが過度に横長にならない最大幅を設定する

### PC・大型タブレット

- 3列表示
- ポータルの最大幅を設定する
- ヘッダーは通常配置とし、画面を占有しすぎない

## 4. 操作フロー

1. 必要に応じて検索語またはカテゴリを選択する
2. コンテンツカードを選択する
3. 対象コンテンツの開始画面へ遷移する
4. 色を変更する場合は「いろを かえる」を開いて選択する

色設定は主要操作ではないため、初期状態では折りたたむ。

## 5. 機能仕様

- 入力:
  - 色設定ボタン
  - 検索文字列
  - カテゴリフィルター
  - コンテンツカード
- 出力:
  - 絞り込み結果
  - 該当なしメッセージ
  - 選択コンテンツへの画面遷移
- 状態遷移: `portal -> <contentId>/home`
- 検索対象:
  - タイトル
  - 説明
  - タグ
- フィルター値:
  - `all`
  - `language`
  - `math`
  - `memory`
  - `shape`

検索とカテゴリはAND条件で適用する。

## 6. データ仕様

- 使用ストレージキー: `ui_theme_v1`
- 保存項目: `warm` / `cool` / `fancy` / `cyber`
- 保存方式: 単一値の上書き
- 検索語とカテゴリは保存しない

## 7. 視認性・アクセシビリティ

- ブラウザのピンチズームを禁止しない
- ページ先頭にスキップリンクを配置する
- 検索入力にラベルを付ける
- 主要ボタンは原則44px以上のタップ領域を確保する
- キーボードのフォーカスを明確に表示する
- カードにアイコン、タイトル、説明、タグ、操作文言を表示する
- 色だけでカテゴリや選択状態を伝えない
- `prefers-reduced-motion` に追従する
- 強制カラーモードでもカード境界を認識できるようにする
- サイバーテーマでも文字と背景のコントラストを維持する

共通基準は [design/子ども向けUI方針.md](design/子ども向けUI方針.md) を参照する。

## 8. 例外・エラー時挙動

- 該当コンテンツがない場合:
  - 検索語またはカテゴリ名を表示する
  - 別の検索語または「ぜんぶ」を試す案内を表示する
- 保存済みテーマが不正な場合:
  - `warm` を使用する
- CSSの高度な機能が非対応の場合:
  - 1列の基本レイアウトで利用を継続する
- 通信失敗:
  - トップ画面自体は外部通信なしのため影響しない

## 9. 受け入れ条件

- [ ] 5件のコンテンツが表示される
- [ ] カードを選択すると対応コンテンツへ移動する
- [ ] 検索とカテゴリのAND条件で絞り込みできる
- [ ] 該当0件時に案内が表示される
- [ ] 色設定を開閉できる
- [ ] 選択した色が再訪時に復元される
- [ ] 360px程度のスマホ縦で横スクロールせずカードを選べる
- [ ] 768px以上で2列表示になる
- [ ] 1024px以上で3列表示になる
- [ ] Tabキーで検索、カテゴリ、カードへ移動できる
- [ ] 200%拡大でも検索、カード選択、色設定が操作できる
- [ ] 動きを減らす設定で操作不能にならない
