# トップ画面 仕様書

## 1. 概要

- 目的: 学習コンテンツを学習順に一覧表示し、子どもが上から順番に開始できるようにする
- 対象ユーザー: 幼児〜小学生と保護者
- 関連コンテンツID: `portal`
- 公開URL: `/`

## 2. 画面構成

- 画面名: まなびのライブラリ
- 主なUI要素:
  - 補助見出し「あそんで まなぼう」
  - タイトル `🎒 まなびのライブラリ`
  - コンテンツ件数 `🎮 7つ`
  - 学習順案内「うえから じゅんばんに やってみよう」
  - 学習段階 `みる → おぼえる → かず → ならび → くらべる → とけい → かく`
  - 折りたたみ式の色設定
  - 検索入力 `🔎 なまえで さがす`
  - カテゴリフィルター
    - `🌈 ぜんぶ`
    - `✏️ こくご`
    - `🔢 さんすう`
    - `🧠 きおく`
    - `🧩 ずけい`
  - STEP順のコンテンツカード一覧
  - 該当なしメッセージ
  - ブラウザ保存の案内
- コンテンツカード:
  1. `🧩` ぴったりシェイプ
  2. `🧠` えもじフラッシュ
  3. `🟡` ドットバースト
  4. `🔢` かずの ならび
  5. `⚖️` どっちが大きい？
  6. `🕐` とけいを よもう
  7. `✏️` かきとりマスター
- カードの操作表示: `▶ あそぶ`

カテゴリで絞り込んだ場合は該当カテゴリだけを表示するため、STEPが連続して見えないことを許容する。`ぜんぶ` では必ずSTEP順に表示する。

## 3. レスポンシブ方針

### スマートフォン

- 1列表示
- ヘッダーはスクロール中も検索・カテゴリへ戻りやすいsticky表示
- 横スクロールはカテゴリボタンなどの補助操作だけに限定
- セーフエリアを考慮する
- カテゴリの絵文字を縮小しすぎない
- 学習順案内は折り返しても横スクロールさせない

### タブレット

- 2列表示
- 検索とカテゴリを横並びにする
- 学習カードが過度に横長にならない最大幅を設定する

### PC・大型タブレット

- 3列表示
- ポータルの最大幅を設定する
- ヘッダーは通常配置とし、画面を占有しすぎない

## 4. 操作フロー

### 基本学習

1. `ぜんぶ` が選択された状態でSTEP 1から順番にカードを選ぶ
2. 対象コンテンツの開始画面へ遷移する
3. コンテンツの終了条件まで学習する
4. 一覧へ戻り、次のSTEPを選ぶ

### 検索・絞り込み

1. 絵文字または文字を手掛かりにカテゴリを選択する
2. 必要に応じて検索語を入力する
3. 表示されたコンテンツカードを選択する

色設定は主要操作ではないため、初期状態では折りたたむ。

## 5. 機能仕様

- 入力:
  - 色設定ボタン
  - 検索文字列
  - カテゴリフィルター
  - コンテンツカード
- 出力:
  - STEP順の一覧
  - 絞り込み結果
  - 該当なしメッセージ
  - 選択コンテンツへの画面遷移
- 状態遷移:
  - 通常コンテンツ: `portal -> <contentId>/home`
  - 独立画面コンテンツ: `portal -> <contentId>`
- 検索対象:
  - タイトル
  - 説明
  - タグ
- フィルター値:
  - `all`
  - `language`
  - `math`
  - `memory`
  - `shape`

検索とカテゴリはAND条件で適用する。

カテゴリボタンの選択状態は、見た目の `is-active` と `aria-pressed` を一致させる。

## 6. データ仕様

- 使用ストレージキー: `ui_theme_v1`
- 保存項目: `warm` / `cool` / `fancy` / `cyber`
- 保存方式: 単一値の上書き
- 検索語とカテゴリは保存しない
- STEP順はコード上の学習経路定義を正とし、利用者による並べ替えは行わない

## 7. 視認性・アクセシビリティ

- ブラウザのピンチズームを禁止しない
- ページ先頭にスキップリンクを配置する
- 検索入力にラベルを付ける
- 主要ボタンは原則44px以上のタップ領域を確保する
- キーボードのフォーカスを明確に表示する
- カードにSTEP、アイコン、タイトル、説明、タグ、操作文言を表示する
- カテゴリと色設定に絵文字と文字を併記する
- 装飾用の絵文字は読み上げ対象から外す
- 色だけでカテゴリや選択状態を伝えない
- `prefers-reduced-motion` に追従する
- 強制カラーモードでもカード境界を認識できるようにする
- サイバーテーマでも文字と背景のコントラストを維持する

## 8. 例外・エラー時挙動

- 該当コンテンツがない場合:
  - 検索語またはカテゴリ名を表示する
  - 別の検索語または「ぜんぶ」を試す案内を表示する
- 保存済みテーマが不正な場合:
  - `warm` を使用する
- CSSの高度な機能が非対応の場合:
  - 1列の基本レイアウトで利用を継続する
- 追加コンテンツのスクリプトを読み込めない場合:
  - 他のコンテンツは利用を継続する
  - 対応カードを選択しても開始できない状態を受け入れず、ビルド検証で検出する
- 通信失敗:
  - トップ画面自体は外部通信なしのため影響しない

## 9. 受け入れ条件

- [ ] 7件のコンテンツが表示される
- [ ] `ぜんぶ` ではSTEP 1〜7の順番で表示される
- [ ] 学習段階の案内に「とけい」が含まれる
- [ ] かずの ならびと時計のカードから各ゲームを開始できる
- [ ] カードを選択すると対応コンテンツへ移動する
- [ ] カテゴリに定義済みの絵文字が表示される
- [ ] 色設定に定義済みの絵文字が表示される
- [ ] カードに `▶ あそぶ` が表示される
- [ ] 検索とカテゴリのAND条件で絞り込みできる
- [ ] カテゴリの見た目と `aria-pressed` が一致する
- [ ] 該当0件時に案内が表示される
- [ ] 色設定を開閉できる
- [ ] 選択した色が再訪時に復元される
- [ ] 360px程度のスマホ縦で横スクロールせずカードを選べる
- [ ] 768px以上で2列表示になる
- [ ] 1024px以上で3列表示になる
- [ ] Tabキーで検索、カテゴリ、カードへ移動できる
- [ ] 200%拡大でも検索、カード選択、色設定が操作できる
- [ ] 動きを減らす設定で操作不能にならない
