# V2.3 レベル・復習・操作性の改修

日付: 2026-10-26

## レベル解放と進捗

- 各ゲームにレベル1〜5。初期状態はレベル1。
- 同じゲームを2回（各5問）クリアするたびに次レベル解放。最終レベル5。
- カードに「レベル 2/5」「つぎまで 1/2」を表示し、進捗バーを伴う。最高レベルはクリア済み表示。
- レベル1の問題IDは従来のgameId:indexを維持。レベル2〜5はgameId:L2:index等と区別。
- 解放済みの最高レベルがゲーム開始時に選ばれる。V2の既存クリア回数も解放判定に利用し、旧記録の破棄はしない。
- 後日復習の期限到来問題を最大2問取り入れ、現在レベルの新しい問題と合わせて5問。

## 正解から次の問題への自動進行

- 正解後は達成エフェクトと解説を約1.75秒表示してから自動進行。
- 5問目は結果へ。手動の「つぎ」も残す。
- 途中でホーム、保護者画面、プロフィール切替、設定画面に移動したとき、古いタイマーで誤進行しないよう停止・ガードする。
- オプションから戻って正解済みなら、改めて自動進行を開始。
- 1問の正答でXPを二重計上しない。

## 当てずっぽう・連打の対策

- 不正解時は約1.2秒から最大2秒まで入力待ち。連続選択を防ぐ。
- 2回目以降の誤答では、解法を示す短いヒントを自動で表示。
- 既存のXPやレベルは失わない。誤答から正解した場合、独力正答とXPを区別する。
- 中断しても罰を与えない。

## 5個単位の数量表示

- 数のドットを5個ずつの枠でまとめる。
- 10個なら5個の枠2つ、20個なら枠4つ。
- スマホでは縦に折り返し、個々のドットが小さくなりすぎないようにする。
- 足し算・引き算・大小比較の共通ドット表示にも利用する。

## カテゴリ分け

- ぜんぶ
- かず・さんすう
- ことば
- かたち・きおく
- せいかつ

ゲームカードの表示をカテゴリで絞り込む。チップにゲーム数を表示し、選択状態を視覚とアクセシビリティ情報の両方で示す。

## 学習データのリセット

- 保護者画面で選択中のキャラクターの「きろくを リセット」を押し、再確認して実行。
- 対象はそのキャラのV2学習記録（XP、クリア、復習予定、セッション数）のみ。
- 音量等の設定、残り3キャラ、過去V1の保存領域は変更しない。
- 必要ならJSONエクスポート後に操作可能。保存失敗時はエラーにしてデータを破棄しない。

## 回帰テスト

- 従来の15ゲーム×80題 = 1,200問。
- 上位レベル4段階×15ゲーム×80題 = 4,800問。
- 合計6,000問で正答の存在、計算、重複排除、レベル解放・復習スケジュールを検証。
- GitHub Actionsで型検査・ビルド・プレビューをチェック。
- 端末別の実操作試験や児童への学習効果は未検証。
