# V2.6 スキルツリー・ステータス・毎日の学習記録

更新日: 2026-10-26。対象: V2.5（19ゲーム）からの非破壊拡張。
関連: PR #28 / Issue #26。

## 子どもの導線
- ホームの大きな **📊 ステータス / 🌳 スキルツリー** から開く。
- ステータス: 累計XP、5問セッション完了数、スキル開放数、復習待ち件数。
- 今日: 取り組んだ問題・体験数、独力正答、練習（なぞり/運動）、クエスト完了数。
- 直近7日: 学習した日数、取り組み数、クリア、獲得XP。
- 直近14日: 日付入り棒グラフ（0件の日も表示）、直近30日: 日別の正答・練習・クリア・XP一覧。
- スキルツリー: 19ゲームごとにLV1～5の連結した5ノードと、開放済み/未開放を表示。開放済みノードをタップするとその難易度で開始。間違って高難度を開けない。
- 分野での絞り込み（算数、ことば、思考、生活、運筆/運動）、ホームへ戻るボタン。
- 無音、静かなモード、キーボード、160%文字サイズでも動作可能。

## 解放の意味
- 現行のゲームごとのクリア回数（completed[gameId]）から計算する。LV1最初から、以後2回クリアごと、最大LV5。
- スキルノードは**挑戦できる難易度**の表示であり、書字・運動・学力の到達認定ではない。過去の記録から現状のレベルを即復元する。
- 苦手になったら解放済みの低いレベルを任意選択可能。結果画面の再挑戦は同じレベルを再開。

## 学習記録と保存
- 既存 `kids_learning_dopagaki_v2_player_1..4` を維持し、schema=2の保存オブジェクトに `daily` を追加する（schema変更なし）。過去のXP、レビュー記録、クリア回数、設定、4キャラの分離は保持。
- 日付キーは端末ローカル `YYYY-MM-DD` 形式。日本時間の午前0時をまたいだ場合も新しい日付で記録。UTCで前日にずれない。
- 1日分のデータは answered（取り組み完了）、independent（ヒントなしで正解）、supported（誤答・ヒント後の正解）、practiced（運筆/体の試行）、rested（休む）、mistakes（誤答クリック回数）、xp（当日獲得）、clears（5問終了）、games（ゲーム別の完了数）。運筆/運動の自己申告を独力正答に混ぜない。
- 記録はクイズ回答が確定したときのみ（既存二重加点ガード）、誤答クリックも別件として一度記録。完了時にclearsを加算。「休憩だけ」もセッション回数に記録できるが、運動レベルは解放しない。
- 今日以前の日付が保存されていないV2.5データから、**過去の日付を推測しない**。合計XP/クリア数は従来保存値から表示可能。日別記録はV2.6導入後の学習分だけ。
- localStorageのみで、同期・クラウド分析・子どもの氏名/写真/運動映像の送信なし。
- 保護者の2段階リセットは対象キャラの`daily`も初期化。音量/文字サイズ設定、他3キャラ、旧V1データは残す。JSONエクスポートは日別記録も含める。
- 破損/不正データは日付形式・整数・ゲームIDを検証して読み取り、悪意のあるHTMLや項目をDOMに表示しない。

## コードの分離
- `src/progression.ts`: 日付キー・学習イベント集約・日別サニタイズ・解放ノード・期間集計の純粋処理。
- `src/progress-ui.ts`: ステータスとスキルツリーのHTML表示。保存や採点ロジックに依存しない。
- `src/progress.css`: ステータス・グラフ・スキルノード・レスポンシブのみ。
- `src/quest-main.ts`: 既存画面の遷移と解答確定イベントから集約処理へ接続する薄いアダプタ。
- `src/engine.ts`: 型にdailyフィールドと初期値を追加。既存19ゲームの採点・出題ロジックは変更なし。
