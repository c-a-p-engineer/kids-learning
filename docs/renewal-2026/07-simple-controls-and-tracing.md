# V2.7: シンプル操作・運筆ガイド・安全な学習データ復旧

日付: 2026-10-26。ユーザー要望：E2Eは後回し、他のタスクを進める。「おおきいのは？」は大きい側を直接タップ。ひらがなは何画か分かりやすく、1画ずつ。枠から出たらその画をやり直す。「の」の形を修正。ひらがなの前に曲線なぞり。

## 使い方

1. **おおきいのは？** 左右2枚の大きな数カードのうち、大きい数字を直接タップ。側を選ぶ別の回答欄なし。5個単位のドットも表示。
2. **せんと カーブ**（新規）：「まっすぐ」「よこ」「カーブ」「なみ」「ぐるり」の5種類。上のカードの順番に配置し、ひらがなの前の手指・目の動きに慣れる。
3. **ゆびで ひらがな**（改修）：「く・し・つ・へ・こ・い・の・て」。書き始めの青い番号と、`2かく ｜ いま 1かくめ` 等の画数・進捗表示。
4. **てんを つなごう**（新規）: 1番の点から指を離さず、2、3…とつながる薄い線をなぞる。指の動きに合わせて線が描かれる。番号ボタンは代替操作だけにする。
5. **でんしゃの めいろ**（新規）: 電車から星まで、連続した道路の上を指でなぞる。道を大きく外れたら最初からやり直し。各問題は到達可能な経路を持つ。タップだけで進める補助操作は折りたたみ表示。
6. **とけいを つくろう**（新規）: **青い短針・オレンジの長針を指で直接つかんで回す**。レベルに応じて時・30分・15分・5分単位へスナップし、正しい時刻なら指を離した時点で成功。小さな針をつかみにくい場合だけ＋／－の補助操作を開ける。
7. **からだ まねっこ**（既存改修）: リズム手拍子、左右、テンポを追加。座ったままの代替動作と休むボタンを維持。

## 運筆の判定・注意点

- ガイドの線と判定の通り道は `src/trace-guides.ts` の**同じ点群**を使う。点群から線を描き、線分までの距離で許容範囲を判定する。別々の判定用・表示用経路を使用しない。
- SVG 240×240基準、許容半径23。大きく外れれば現在の1画だけ失敗としてクリアし、再度青い開始番号から試行。すでに完成した画は残す。
- 点は指定順で通り、最後の点の近くで指を離したらその画が完成する。複数画は画ごとに指を離して次へ。連続線や筆圧の医学的評価はしない。
- 「の」は**1画**で、意図しない二重ループを取り除いたガイドへ変更。「こ」「い」は**2画**。その他は1画。
- 多少の指の揺れは許容する。時間制限、XP没収、やり直し回数制限なし。タッチが難しい場合は番号付きの点を順番に押す代替操作。
- 描いた軌跡の保存・外部送信なし。成果は練習参加としてカウントし、翌日想起や運動能力・書字能力の測定へ混ぜない。

## 保存処理とバックアップ復元

- 保存処理は `src/storage.ts` に分離。既存V2 schema=2の `kids_learning_dopagaki_v2_player_N` をそのまま使用。V1・他の3キャラのキー不変。
- 保護者画面からバックアップJSONを選択、キャラの保存枠と形式を検証。最大3MB。XP・完了回数・日別履歴の変更前後を表示してから明示的に復元。
- 空のschemaだけの偽バックアップ、不正JSON、他のキャラ、フォーマット違いを拒否。成功前は現行保存を書き換えない。保存失敗時もメモリ上の旧記録を保つ。
- セッション生成・次問への遷移・正答XPの分類は `src/session.ts` の純粋関数へ分離。実際の画面・音声・タイマーと依存を切る。
- 自動E2Eは**ユーザー指定により延期**。型検査、出題/入力/保存/運筆幾何の単体テスト、ビルド、Pagesプレビューで検証。

## 今後の改修候補

- 実機での指なぞり感、枠の幅や難易度の保護者設定、筆順や文字字形の教育現場の指導と整合したガイド監修。
- 迷路の探索性/別経路のデザイン改善、時計針の当たり判定の端末別評価、復習の学習到達度に応じたレベル提案。
- 保存破損時の修復、CSVやバックアップ転送、CSSの重複削除など。

この仕様は家庭学習を補助するもので、療育効果や書字能力の改善を保証しない。
