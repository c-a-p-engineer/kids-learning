# ぴったりシェイプ 仕様書

## 1. 概要
- 目的: 図形の一致判定と空間把握を遊びながら鍛える
- 対象ユーザー: 幼児〜小学生
- 関連コンテンツID: fit-shape

## 2. 画面構成
- 画面名: スタート / ゲーム / リザルト
- 主なUI要素:
  - 難易度選択（かんたん3こ / ふつう5こ / むずかしい8こ）
  - スコア表示、30秒タイマー
  - 図形シルエット（配置先）
  - ドラッグ可能図形ブロック
  - 直近履歴表示
- レイアウト方針（スマホ縦優先）:
  - ゲームキャンバスは画面高に応じた可変高さ
  - 重ね合わせ操作を優先して余白を最小化

## 3. 操作フロー
1. 難易度を選ぶ
2. 同じ形のシルエットに図形をドラッグして重ねる
3. 全一致で次ラウンド、30秒経過で結果表示

## 4. 機能仕様
- 入力: pointer操作（ドラッグ）、難易度選択、再挑戦
- 出力: スコア、履歴、新記録表示
- 状態遷移: start -> game -> result -> start
- バリデーション/制約:
  - 一致判定は図形中心点距離しきい値で判定
  - 1ラウンド全消去で自動再生成
  - 各シルエット枠は対応図形と同系色で表示し、正解判別を補助する
  - 図形数が多い場合はシルエットと図形を複数行（2段）に配置し、画面内に収まるよう自動レイアウトする

## 5. データ仕様
- 使用ストレージキー: `shape_match_history_v1`
- 保存項目: id/date/difficulty/difficultyLabel/score
- 保持件数/削除ポリシー: 最新50件

## 6. 表示・演出仕様
- 文言: 「ぴったりシェイプ」「シルエットにかさねてね」など
- 色/テーマ連動: app共通テーマ変数を利用
  - サイバーテーマではシルエット（穴）が見えにくくならないよう、専用の塗り/線色と不透明度を適用
- アニメーション/SE: マッチ時pop、ラウンドクリア時紙吹雪、効果音

## 7. 例外・エラー時挙動
- データなし時: 履歴に「まだ きろくが ありません」
- 通信失敗時: 該当なし（外部通信なし）
- 非対応端末時: pointer非対応環境は動作保証外

## 8. 受け入れ条件（Yes/No）
- [ ] 3難易度すべて開始できる
- [ ] ドラッグで図形移動し、一致でスコア加算される
- [ ] 30秒経過で必ず結果画面に遷移する
- [ ] 履歴保存と新記録表示が動作する
