# どっちが大きい？ 仕様書

## 1. 概要
- 目的: 数値の大小比較を素早く判断する
- 対象ユーザー: 初級算数の比較学習者
- 関連コンテンツID: larger-number

## 2. 画面構成
- 画面名: スタート / ゲーム / 結果 / スコア履歴
- 主なUI要素:
  - レベル選択（やさしい/ふつう/むずかしい）
  - 選択カード（数値、りんご表示）
  - タイマー、スコア、コンボ表示
  - 履歴一覧
- レイアウト方針（スマホ縦優先）:
  - ゲーム中は2〜3択カードを画面高に合わせて伸縮
  - りんご表示はビューポートサイズに応じて可能な限り大きく表示

## 3. 操作フロー
1. レベルを選択
2. より大きい数のカードを選ぶ
3. タイムアップで結果表示

## 4. 機能仕様
- 入力: レベル選択、選択カードタップ、履歴操作
- 出力: スコア、正解数、フィードバック、履歴
- 状態遷移: start -> game -> result / scores
- バリデーション/制約:
  - easy: 1〜10（2択）
  - normal: 1〜20（2択）
  - hard: 1〜100（3択・りんご表示なし）

## 5. データ仕様
- 使用ストレージキー: `math_game_v8_history`
- 保存項目: id/date/level/levelLabel/score/corrects/total
- 保持件数/削除ポリシー: 最新50件、手動全削除可

## 6. 表示・演出仕様
- 文言: 「どっちがおおきい？」「タイムアップ！」等
- 色/テーマ連動: appテーマ色を利用
- アニメーション/SE: 正誤フィードバック、shake、コンボ表示、効果音

## 7. 例外・エラー時挙動
- データなし時: 履歴に「まだ きろくが ないよ」
- 通信失敗時: 該当なし（外部通信なし）
- 非対応端末時: 表示のみでゲーム進行可能

## 8. 受け入れ条件（Yes/No）
- [ ] 各レベルで問題生成範囲が正しい
- [ ] 正解時のみスコア/コンボが加算される
- [ ] easy/normalのりんご表示が大きく視認しやすい
- [ ] 履歴保存と削除が動作する
