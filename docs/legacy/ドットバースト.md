# ドットバースト 仕様書

## 1. 概要
- 目的: ドット個数の瞬時認識トレーニング
- 対象ユーザー: 数の感覚を養いたい学習者
- 関連コンテンツID: dotburst

## 2. 画面構成
- 画面名: スタート / ゲーム / 結果 / 履歴
- 主なUI要素:
  - タイマー、スコア、正解/不正解/コンボ
  - ドット表示エリア
  - 数字入力ボタン
  - 履歴表示（日時順/スコア順）
- レイアウト方針（スマホ縦優先）:
  - ルート高さはビューポート連動で可変
  - 最小高さを確保し、不要スクロールを抑制

## 3. 操作フロー
1. 難易度選択（かんたん/ふつう）
2. ドットを数えて数字ボタンを選択
3. 30秒経過で結果表示

## 4. 機能仕様
- 入力: 数字ボタン、履歴操作、並び替え
- 出力: スコア更新、フィードバック表示、履歴保存
- 状態遷移: start -> game -> result / history
- バリデーション/制約:
  - かんたん: 1〜5、ふつう: 1〜10
  - ドットサイズと配置は表示領域に応じて可変

## 5. データ仕様
- 使用ストレージキー: `dot_burst_v8`
- 保存項目: score/ok/ng/date/level/timestamp
- 保持件数/削除ポリシー: 最新50件

## 6. 表示・演出仕様
- 文言: 「DOT BURST」「おしまい！」など
- 色/テーマ連動: appテーマ色を利用
- アニメーション/SE: ドットpop、正誤フィードバック、効果音

## 7. 例外・エラー時挙動
- データなし時: 履歴に「きろくがありません」
- 通信失敗時: 該当なし（外部通信なし）
- 非対応端末時: visualViewport非対応時はinnerHeightで代替
