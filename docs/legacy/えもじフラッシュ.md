# えもじフラッシュ 仕様書

## 1. 概要
- 目的: 記憶保持と想起のトレーニング
- 対象ユーザー: 記憶系クイズを楽しむ学習者
- 関連コンテンツID: flashcard

## 2. 画面構成
- 画面名: レベル選択 / 表示 / クイズ / 結果 / 履歴
- 主なUI要素:
  - レベルボタン（5段階）
  - 絵文字カード表示
  - 2択クイズ
  - 結果表示、履歴オーバーレイ
- レイアウト方針（スマホ縦優先）:
  - 1カラム構成、主要ボタンは親指到達範囲に配置

## 3. 操作フロー
1. レベル選択
2. 絵文字を順番に記憶
3. クイズ回答
4. 結果確認と履歴閲覧

## 4. 機能仕様
- 入力: レベル選択、選択肢タップ、履歴操作
- 出力: 正誤フィードバック、スコア、履歴
- 状態遷移: idle -> game -> quiz -> result
- バリデーション/制約:
  - レベル: やさしい/ふつう/ちょいむず/むずかしい/げきむず
  - レベルごとに表示枚数・速度・クイズ数を設定

## 5. データ仕様
- 使用ストレージキー: `emoji_v10_history`
- 保存項目: id/date/levelName/score/accuracy/emojiList
- 保持件数/削除ポリシー: 最新50件、手動クリア可

## 6. 表示・演出仕様
- 文言: 「レベルをえらぼう！」「これはあったかな？」等
- 色/テーマ連動: appテーマ色を利用
- アニメーション/SE: 正誤オーバーレイ、読み上げ、効果音

## 7. 例外・エラー時挙動
- データなし時: 履歴に「きろくなし」
- 通信失敗時: 該当なし（外部通信なし）
- 非対応端末時: 音声未対応時は視覚情報のみで進行

## 8. 受け入れ条件（Yes/No）
- [ ] 5レベルすべて開始できる
- [ ] レベル設定どおりに枚数/クイズ数が反映される
- [ ] 正誤判定と結果表示が一致する
- [ ] 履歴閲覧と履歴クリアが動作する
