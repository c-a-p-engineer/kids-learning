# 100そろばん 仕様書

## 1. 概要

- 目的: 0〜100の数量、10のまとまり、十の位・一の位を視覚的に理解する
- 対象ユーザー: 年長〜小学校低学年を中心とする子ども
- 関連コンテンツID: `hundred-abacus`
- 公開URL: `/hundred-abacus`
- 学習順: STEP 4
- 前後関係: ドットバースト → 100そろばん → かずの ならび

## 2. 学習モデル

- 10個の玉を10段、合計100個表示する
- 左側へ寄った玉を「数えた玉」とする
- 上の段から順番に埋める標準配置とする
- 37は「10個の段が3段＋次の段に7個」として表示する
- 同じ数に複数の並べ方を持たせない
- 5個目と6個目の間に空間を設け、5と10のまとまりを認識しやすくする
- 100は「10が10こ、1が0こ」と表示する

## 3. 画面構成

### 開始画面

- `🎯 もんだい`
  - 1回10問
- `👐 じゆうに うごかす`
  - 1回3分
- `📊 きろくを みる`
- `🏠 いちらん`

終了条件をモード選択ボタン内に表示する。

### 問題レベル選択

| レベル | 出題範囲 | 表示 |
|---|---:|---|
| `to10` | 0〜10 | 🐣 10まで |
| `to20` | 0〜20 | 🦁 20まで |
| `to100` | 0〜100 | 🚀 100まで |

## 4. 玉の操作

### タッチ・マウス

- 任意の玉をタップすると、その玉までを数えた状態にする
- 現在値より前の玉をタップすると数を減らす
- 玉の上をドラッグすると数を連続して変更する
- `0にもどす` で全ての玉を戻す
- 問題レベルの上限を超える玉は操作不可として薄く表示する

### キーボード

そろばん全体をフォーカス可能にする。

| キー | 動作 |
|---|---|
| `←` / `↓` | 1減らす |
| `→` / `↑` | 1増やす |
| `PageDown` | 10減らす |
| `PageUp` | 10増やす |
| `Home` | 0にする |
| `End` | 現在モードの最大値にする |

値は0〜現在モードの上限に制限する。

## 5. 問題モード

### セッション

- 1回10問
- 問題数で終了し、時間制限は設けない
- `数を作る` 5問、`数を読む` 5問
- 同じ形式が4問以上連続しない
- 同じ数を連続出題しない
- 10問終了後に自動で結果画面へ移動する
- 途中離脱したセッションは保存しない

### 数を作る

- 指定された数になるように玉を動かす
- 目標値と現在値が約600ミリ秒一致すると自動正解にする
- `できた` ボタンは設けない
- 目標値が0の場合は開始値を1にして、0へ戻す操作を必要とする

### 数を読む

- あらかじめ配置された玉の数を3択で答える
- 誤答した選択肢は薄くし、同じ問題を継続する
- 強い警告音、減点、失敗表現は使わない

### ヒント

`💡 わからない` を押すたびに段階的に表示する。

1. 10の段または十・一の分解を示す
2. `10が○こ、1が○こ` を明示する
3. 答えを表示し、ヒント回答として完了する

ヒントを一度でも使った問題は、正解時に `ヒントでできた` として記録する。

### 出題バランス

100までのレベルでは、1セッション内に次の種類を含める。

- 0
- 1桁の数
- 10の倍数
- 一の位が5の数
- 一般的な2桁の数
- 100

## 6. フリーモード

- 1回3分
- 開始前に `3ぷんで おしまい` と表示する
- 残り時間と進捗バーを常時表示する
- 初回操作前は `たまを タップしてみよう` と表示する
- 現在値、`10が○こ`、`1が○こ` を表示する
- 3分経過時に自動終了する
- 終了後に自動再開しない
- 得点、ランキング、コンボ、速度評価を表示しない
- 3分完了時のみ履歴を保存する

## 7. 結果画面

### 問題モード

- `ひとりでできた` 問題数
- `ヒントでできた` 問題数
- 自力正解数に応じた星

| 自力正解数 | 星 |
|---:|---|
| 10 | ⭐⭐⭐ |
| 7〜9 | ⭐⭐ |
| 0〜6 | ⭐ |

### フリーモード

- 玉を動かした回数
- 最後に作っていた数

### 共通操作

- `🔁 もういちど`
- `🎮 モードをえらぶ`
- `🏠 いちらんへ`

## 8. 保存データ

- 使用ストレージキー: `hundred_abacus_v1_history`
- 最大保持件数: 50件
- 51件目以降は古い履歴から削除する
- 子ども向け履歴画面に削除操作は表示しない

```ts
interface AbacusHistoryRecord {
  id: number;
  completedAt: string;
  mode: "problem" | "free";
  level: "to10" | "to20" | "to100" | null;
  independentCount: number | null;
  assistedCount: number | null;
  totalQuestions: number | null;
  durationSeconds: number;
  operationCount: number;
  finalValue: number;
}
```

## 9. 音・アニメーション

- 玉の移動時は短い小音量のクリック音を鳴らす
- 連続ドラッグ時は音を間引く
- 正解時は短い明るい音を鳴らす
- 誤答時は短く弱い音にする
- 強い点滅、画面全体の揺れ、長い紙吹雪は使わない
- `prefers-reduced-motion` では移動・押下演出を停止する

## 10. レスポンシブ・アクセシビリティ

- 360×640程度のスマートフォン縦を最低基準とする
- 10段のそろばんを横スクロールなしで表示する
- 主要ボタンは原則44px以上にする
- タブレットでは玉と余白を拡大するが、最大幅を設ける
- 現在値を `aria-live="polite"` で通知する
- 正解・ヒント結果をライブ領域で通知する
- 各段に段番号と玉数の読み上げ情報を付ける
- 色だけに依存せず、配置、形、文字を併用する
- 文字を200%に拡大しても縦スクロールで操作を継続できる

## 11. 例外・エラー時挙動

- 保存データが不正な場合はその履歴を無視する
- `localStorage` にデータがない場合は `まだ きろくが ないよ` と表示する
- 音声APIが利用できなくても操作を継続する
- 画面離脱時はタイマー、正解待機、次問題待機を停止する
- 直接URLから開いた場合も一覧へ戻れる
