# 100そろばん 仕様書

## 1. 概要

- 目的: 0〜100の数量、5と10のまとまり、十の位・一の位を視覚的に理解する
- 対象: 年長〜小学校低学年を中心とする子ども
- contentId: `hundred-abacus`
- 公開URL: `/hundred-abacus`
- 学習順: STEP 4
- 前後関係: ドットバースト → 100そろばん → かずの ならび

## 2. 学習モデル

- 10個の玉を10段、合計100個表示する
- 左側の玉は数に入れず、右側へ移動した玉を数に入れる
- 上の段から順番に数へ入る標準配置とする
- 37は、3段が右に10個、4段目が右に7個の状態とする
- 各段は5個単位で赤・黄色を切り替える
- 段ごとに色の開始順を変え、隣の段を見分けやすくする
- 玉を動かしたときは音とアニメーションで操作結果を示す

## 3. モード

### 問題モード

- 1回10問
- レベルは `10まで`、`20まで`、`100まで`
- 問題形式は**指定された数へ玉をそろえる問題だけ**とする
- `この数はいくつ？` の3択問題は出題しない
- 現在値が目標値と約600ミリ秒一致すると自動正解にする
- `できた` ボタンは設けない
- 目標が0の場合は1から開始し、玉を左へ戻す操作を必要とする
- 自力完了とヒント使用を分けて記録する

### 自由操作モード

- **時間制限なし**
- 自動終了しない
- 利用者が `🏁 おわる` を押すまで続けられる
- `0にもどす` を利用できる
- 終了時に操作回数、最後の数、利用時間を履歴へ保存する
- 得点、ランキング、コンボは表示しない

## 4. 玉の操作

### タッチ・マウス

- 左側の玉を押すと右へ移動して数が増える
- 右側の玉を押すと左へ戻って数が減る
- 1の状態で右側の1個を押すと0へ戻る
- ドラッグで連続して値を変更できる
- 問題レベルの上限を超える玉は操作不可とする

### キーボード

| キー | 動作 |
|---|---|
| `←` / `↓` | 1減らす |
| `→` / `↑` | 1増やす |
| `PageDown` | 10減らす |
| `PageUp` | 10増やす |
| `Home` | 0にする |
| `End` | 現在モードの最大値にする |

## 5. ヒント

1. `10が○こ、1が○こ` を表示する
2. 全て右へ動かす段数と、次の段で動かす玉数を表示する
3. 正解の配置を表示し、ヒント完了として次へ進む

## 6. 音・アニメーション

- 玉が動くたびに短い操作音を鳴らす
- 数が増える操作と減る操作で音程を変える
- 5の倍数と10の倍数では区切り音を追加する
- 玉は約0.36秒で左右へ移動する
- 複数個動く場合は短い時間差を付ける
- 動いた玉だけ一時的に拡大・発光する
- `prefers-reduced-motion` では即時表示する

## 7. 履歴

- 保存キー: `hundred_abacus_v1_history`
- 最大50件
- 問題モードは10問完了時に保存する
- 自由操作モードは `おわる` を押したときに保存する
- 一覧やページ離脱だけでは自由操作の履歴を保存しない

```ts
interface AbacusHistoryRecord {
  id: number;
  completedAt: string;
  mode: "problem" | "free";
  level: "to10" | "to20" | "to100" | null;
  independentCount: number | null;
  assistedCount: number | null;
  totalQuestions: number | null;
  durationSeconds: number;
  operationCount: number;
  finalValue: number;
}
```
