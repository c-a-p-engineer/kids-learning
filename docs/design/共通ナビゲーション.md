# 共通ナビゲーション仕様

## 1. 目的

文字をまだ読めない、または文章の理解に時間がかかる子どもでも、絵を手掛かりに移動先と操作の意味を判断できるようにします。

同じ意味の操作は、コンテンツごとに文言や色を変えず、同じ絵文字・短い言葉・位置・形を使用します。

## 2. 共通アイコン

| 絵文字 | 意味 | 表示例 | 遷移先 |
|---|---|---|---|
| 🏠 | 学習コンテンツの一覧 | `🏠 いちらん` | まなびのライブラリ |
| ↩️ | 一つ前の画面 | `↩️ もどる` | 問題一覧、直前のメニュー |
| 🎮 | コンテンツ内の開始メニュー | `🎮 メニュー` | 難易度選択、タイトル画面 |
| ✖️ | 重ねて表示した画面を閉じる | `✖️ とじる` | 元の画面 |
| 🔁 | 同じ操作を再実行する | `🔁 もういちど` | 再挑戦、再生 |
| 📜 / 📊 | 学習記録を確認する | `📜 きろく` | 記録画面 |
| 🔊 | 音声で確認する | `🔊 よむ` | 現在の文字を読み上げる |
| 🧹 | 現在の入力だけを消す | `🧹 やりなおす` | 同じ問題 |
| 💮 | 完了を確定する | `💮 できた！` | 次の問題 |

`🏠` と `🎮` は混同しないこと。`🏠` はアプリ全体の一覧、`🎮` は現在のコンテンツ内のメニューを表します。

## 3. 表示ルール

- 絵文字だけにせず、短い文字ラベルを併記する
- 絵文字には `aria-hidden="true"` を付け、ボタン本体に操作内容の `aria-label` を設定する
- 戻るボタンは各コンテンツ上部の共通ヘッダーに置く
- 書字・運筆練習中の戻るボタンも画面上部に置き、操作画面の下まで探させない
- 主要ナビゲーションは高さ52px以上、その他の操作は48px以上を基準にする
- ボタンは角丸、境界線、影を共通化し、押したときに沈む表現を付ける
- 色だけで操作の種類を区別しない

## 4. 共通ヘッダー

各コンテンツの開始画面では、以下の構成を使用します。

1. 左側: コンテンツを表す絵文字と短いタイトル
2. 右側: `🏠 いちらん`
3. スクロール中も上部に残る、または画面開始時に必ず見える位置

対象:

- かきとり
- ドットバースト
- えもじフラッシュ
- どっちがおおきい？
- ぴったりシェイプ
- かずの ならび
- とけいを よもう
- えんぴつれんしゅう

## 5. 独立学習画面

次のコンテンツは、既存の書字用ホーム画面とは別の独立画面として表示します。

- `number-sequence-experience`
- `clock-reading-experience`
- `pencil-practice-experience`

独立画面が表示されている間は、かきとり用の `れんしゅう / おうち` タブを隠します。直接URLから開いた場合も同じ状態にします。

一覧へ戻った後はタブを表示せず、かきとりを開いた場合は既存ルーターの状態に従って再表示します。

## 6. カテゴリ・設定

トップ画面のカテゴリにも絵文字を使用します。

- `🌈 ぜんぶ`
- `✏️ こくご`
- `🔢 さんすう`
- `🧠 きおく`
- `🧩 ずけい`

色設定:

- `☀️ あたたかい`
- `💧 すずしい`
- `🌸 かわいい`
- `🤖 サイバー`

## 7. 実装

- `src/common-ui.ts`
  - 既存ボタンのイベント処理を変更せず、絵文字、短いラベル、アクセシブルな名前、共通クラスを付与する
  - 書字練習の戻るボタンを上部ヘッダーへ移動する
  - 独立学習画面の表示状態を監視し、書字用タブの混在を防ぐ
  - 数の並び、時計読み、えんぴつれんしゅうの実行エントリを読み込む
- `src/styles/common-ui.scss`
  - 共通ボタン、共通ヘッダー、タイトル、スマホ幅、テーマ別表示を定義する
- `src/index.html`
  - `main.ts` の後に `common-ui.ts` を読み込む

ゲーム状態と保存形式は各コンテンツの実装に委ねます。

## 8. レスポンシブ

- 最小幅320pxでタイトルと戻るボタンを同時に表示できること
- スマートフォンでは文字を短くし、絵文字を縮小しすぎないこと
- タブレットではボタンだけを過度に拡大しないこと
- ノッチとホームインジケーターを考慮すること

## 9. アクセシビリティ

- 絵文字は視覚的補助であり、読み上げ名称はボタンの `aria-label` で提供する
- キーボードフォーカスを消さない
- 200%拡大でも戻る操作を表示する
- `prefers-reduced-motion: reduce` では押下アニメーションを省略可能にする
- 強制カラーモードでもボタン境界を維持する
