# 共通エフェクト方針

## 目的
11教材全体で「触ると楽しい」「成功が伝わる」「終えたことを喜べる」体験を統一する。スコア・出題・保存済み学習記録は変更しない。

## 表示
- `もりもり`（初期値）: パステルネオン背景、立体カード、虹色プログレス、揺れるアイコン、タップ波紋、成功パーティクル、コンボ、終了祝福。
- `ひかえめ`: 点数等の意味表示は維持しつつ、粒子数を削減して常時アニメーションを抑える。
- `おやすみ`: 装飾アニメーション・重ね合わせエフェクトを止める。
- `prefers-reduced-motion: reduce` 時は端末の設定を優先して実効エフェクトを止める。
- 誤答には成功の祝福を出さない。交通横断の衝突終了も例外。
- 背景の点滅や操作を待たせる演出を行わず、視認性・操作性を優先する。

## 音声
ごほうび音は初期OFF。任意ON。ブラウザが再生を許可しなくても学習は継続可能。各ゲームが既に持つ音の設定は変更しない。

## 実装
- `src/juicy-effects.ts`: 共通の装飾用イベント監視、効果音、タップ波紋、成功演出、設定。
- `src/styles/juicy-effects.scss`: 背景・カード・アニメーション。
- `src/common-ui.ts` から共通読み込み。独立したバルーンアタックは独立エントリから読み込む。
- 特定の成功画面・正解フィードバックをDOM上で検知。DOMだけで検知できないコンテンツは `kids-learning:reward` CustomEvent により明示通知できる。
- `localStorage`: `kids_fx_level_v1`, `kids_fx_sound_v1` の新規キーのみ。従来の記録・テーマキーを変更しない。

## Scenario QA
1. 初回: 既定の「もりもり」が選択され、学習カードを選択できる。
2. 正解: 正解フィードバック・コンボを短く表示する。
3. 不正解: 成功扱いしない。交通横断の衝突結果を祝福しない。
4. 連打: オーバーレイは操作を妨げず、記録が壊れない。
5. 結果: 終了画面は操作待ち時間なしで表示する。
6. 設定: 3モードと音声ON/OFFを切り替え、再訪時に保持する。
7. 配慮: OSで動きを減らす設定の時は強制アニメーションしない。
8. 画面: スマホ360px・タブレット768px・PC・200%拡大・キーボード・深いURLを確認する。

## 制約
エフェクトはUIの補助機能。既存の学習結果を変えず、コンテンツ固有のタイマー・保存・カメラ・描画処理を改変しない。
