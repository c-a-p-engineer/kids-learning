# 学習セッション方針

## 目的

子どもが同じコンテンツを区切りなく続けることを防ぎ、保護者が学習時間を管理しやすくします。

## 決定事項

- 反復クイズ型ゲームには必ず時間制限を設ける
- 時間制限なしモードは設けない
- ゲーム開始前に終了時間を明示する
- タイマー終了後は自動的に結果画面へ移動する
- 再挑戦は結果画面またはメニューから明示的に開始する

## 例外

書字課題など、開始時点で回数または問題数が確定しており、自動的に完了する課題は問題数による終了を認めます。終了条件のない自由練習は追加しません。

## 新規コンテンツ確認

- [ ] 開始前に終了条件が分かる
- [ ] 子どもが操作しなくてもセッションが終了する、または問題数完了で終了する
- [ ] 時間制限なし・無限継続モードがない
- [ ] 終了後に結果または完了画面を表示する
- [ ] 再開始には明示的な操作が必要である
