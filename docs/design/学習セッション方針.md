# 学習セッション方針

## 目的

子どもが学習コンテンツを安全に利用でき、保護者が終了条件を理解できるようにします。

## 基本方針

- 反復クイズ型ゲームには時間または問題数の終了条件を設ける
- 運筆チャレンジなど達成数を競う課題には時間制限を設ける
- 身体を動かすゲームは、短いラウンドと休憩を前提にする
- 開始前に終了条件を明示する
- 自動終了する課題は終了後に結果画面へ移動する
- 再挑戦は結果画面またはメニューから明示的に開始する

## 終了方式

### 時間制

- 反復クイズ
- えんぴつれんしゅうのように、制限時間内の達成数を記録する課題
- 身体活動を伴うゲーム

### 問題数制

- 開始時点で問題数が確定している課題
- 問題完了時に自動で終了できる課題

### 利用者終了制

学習目的が自由な試行錯誤そのものであり、得点や連続プレイを促す設計でない場合は、明示的な終了ボタンを備えた時間制限なしモードを認めます。

時間制限なしモードでは次を必須とします。

- `おわる` ボタンを常時表示する
- 得点、ランキング、コンボを設けない
- 終了時だけ履歴を保存する

## 身体活動ゲームの追加条件

- 1ラウンドは原則30〜90秒程度とする
- ラウンド間に休憩または水分補給の案内を表示する
- 端末は手に持たず、安定した台へ固定する前提にする
- 画面へ近づきすぎないよう開始前に距離確認を行う
- ジャンプなし、座位などの低負荷モードを用意する
- 速度だけで評価せず、参加・到達・左右の使用などを記録候補とする
- カメラ映像を保存・送信しない設計を標準とする

## 新規コンテンツ確認

- [ ] 開始前に終了方式が分かる
- [ ] クイズまたは競争型課題に時間・問題数の区切りがある
- [ ] 時間制限なしの場合、明示的な終了操作がある
- [ ] 時間制限なしの場合、過度な継続を促す得点・ランキング・コンボがない
- [ ] 身体活動ゲームでは休憩と安全距離を案内する
- [ ] 終了後に結果または完了画面を表示する
