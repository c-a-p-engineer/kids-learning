# しんごうを わたれ！ 仕様書

## 1. 概要

- contentId: `traffic-crossing`
- 公開URL: `/traffic-crossing`
- 学習経路: `STEP 2`
- 目的: 周囲を見る、待つ、途中で止まる、再び動くという判断を短いゲームで反復する
- 対象: 幼児〜小学校低学年
- 1プレイ: 横断1回。ゴール到達または車との衝突で終了
- LV1〜LV4で1〜4車線へ段階的に増える
- 成功時は横断タイムを表示し、LV別ベスト5へ登録する
- 実際の交通ルール判定や安全保証には使用しない。注意・停止操作を遊びとして練習する教材とする

## 2. 操作

- `おして すすむ` ボタンを押している間だけ子どもキャラクターが前進する
- 指を離すと即停止する
- ボタン領域から指が外れた場合も停止する
- キーボードでは Space / Enter を押している間だけ進む
- 車との当たり判定が成立した時点でそのプレイを終了する
- ゲーム開始から終了までの経過時間を0.1秒単位で画面へ表示する
- 画面が非表示になり `requestAnimationFrame` が停止している時間は、ゲーム内経過時間へ実質加算しない

## 3. レベル

### LV1・1車線

- 車線: 1
- 車: 左から右へ進む
- 目的: 1方向の車を確認し、進む・止まる操作を覚える
- 車ごとに速度と次の出現間隔を範囲内でランダム化する

### LV2・2車線

- 車線: 2
- 上側車線: 左から右
- 下側車線: 右から左
- 目的: 左右両方向へ注意を切り替え、必要な場所で停止する
- 各車線で速度と出現間隔を独立してランダム化する

### LV3・3車線

- 車線: 3
- 上側: 左から右
- 中央: 右から左
- 下側: 左から右
- 目的: 3つの危険位置を順に確認し、停止・再開を複数回切り替える
- 各車線で速度と出現間隔を独立してランダム化する

### LV4・4車線

- 車線: 4
- 上から `右進行 / 左進行 / 右進行 / 左進行` の交互方向
- 目的: 見る場所を4か所へ増やし、より頻繁に注意を切り替える
- 各車線で速度と出現間隔を独立してランダム化する

## 4. 車のランダム性

毎回同じタイミングを暗記して突破するゲームにしないため、車ごとに速度と車間を変化させる。

| レベル | 車線位置・方向 | 速度範囲 | 基本車間 |
|---|---|---:|---:|
| LV1 | 1車線・右進行 | `0.16〜0.31` | `1.35〜3.6秒` |
| LV2 | 上・右進行 | `0.17〜0.33` | `1.1〜3.0秒` |
| LV2 | 下・左進行 | `0.18〜0.34` | `1.15〜3.15秒` |
| LV3 | 上・右進行 | `0.17〜0.34` | `1.05〜2.85秒` |
| LV3 | 中・左進行 | `0.18〜0.35` | `1.0〜2.75秒` |
| LV3 | 下・右進行 | `0.19〜0.36` | `1.05〜2.9秒` |
| LV4 | 1・右進行 | `0.18〜0.35` | `0.95〜2.7秒` |
| LV4 | 2・左進行 | `0.19〜0.36` | `0.9〜2.55秒` |
| LV4 | 3・右進行 | `0.18〜0.36` | `0.95〜2.6秒` |
| LV4 | 4・左進行 | `0.20〜0.37` | `0.9〜2.5秒` |

- 速度は0〜1の正規化座標における毎秒移動量
- 一定確率で基本範囲よりやや短い連続車、または長めの安全時間を作る
- 極端な高速車・連続出現だけに偏らないよう上下限を持たせる
- 車種絵文字は `🚗 / 🚕 / 🚙` からランダムに選ぶ
- 車絵文字の見た目が進行方向と一致するよう、右進行時は水平反転する
- プレイヤー速度と衝突判定サイズはレベル間で固定する

ランダム性があるため、タイムは標準化された能力測定値ではなく、遊びとしてのハイスコアとして扱う。

## 5. ゲームループ

1. LV1〜LV4からレベルを選ぶ
2. 子どもキャラクターは画面下端から開始
3. 車は各車線へランダムな速度・時間差で出現する
4. プレイヤーは長押しで前進、離して停止する
5. 車との接触時は `ぶつかった！ おしまい` を表示して即終了
6. 衝突時は失敗音を鳴らし、Vibration API対応環境では短い振動を出す
7. 上端のゴールへ到達すると成功
8. 成功時のみタイムをLV別ベスト5へ登録する
9. 結果画面で今回のタイム・順位・ベスト5を表示する
10. 同じレベルを再挑戦、またはレベル選択へ戻る

## 6. 衝突フィードバック

- 衝突時は低い音を2段階で鳴らして、成功音と明確に区別する
- 対応ブラウザ・端末では `navigator.vibrate([120, 60, 180])` 相当の短い振動を行う
- Vibration API非対応・無効化・拒否環境では振動なしで継続し、音のみで失敗を示す
- 振動機能の失敗をゲーム全体のエラーにしない
- 血液・負傷・恐怖を強くする表現は使用しない

## 7. シミュレーション

- プレイヤー位置と車位置は0〜1の正規化座標で管理する
- 描画サイズとゲーム速度・当たり判定を分離する
- `requestAnimationFrame` で更新する
- フレーム間隔は上限を設け、復帰直後の大きな時間差でワープしないようにする
- タイムはゲームループで処理したdeltaの累積で計測する
- 画面離脱、結果画面、一覧へ戻る操作でループを停止する
- 速度・車間のランダム化はプレイヤー速度や当たり判定サイズを変更しない

## 8. 表示

- 衝突時に血液・負傷表現は使用しない
- `⚠️`、低い失敗音、対応端末の振動で失敗を示す
- 成功時は `🏁 わたれた！` と上昇音を出す
- ベストタイム更新時は `🏆 ベストタイム！` と順位を表示する
- プレイ中は `⏱️ 0.0びょう` 形式で経過時間を表示する
- レベル選択画面ではLV1〜LV4それぞれの現在ベストを表示する
- 結果画面では今回のタイムと現在のベスト5を表示する
- 車の進行方向と絵文字の前後方向を一致させる
- 道路、車線、ゴール、キャラクター、長押しボタンを視覚的に分離する
- スマホ縦を基準にし、タブレットではゲーム領域を過度に拡大しない
- 主要ボタン44px以上
- `prefers-reduced-motion`、Tab操作、文字拡大を妨げない

## 9. 保存データ

- 使用キー: `traffic_crossing_v1_scores`
- 既存キー名を維持し、フィールド追加だけで後方互換にする
- 形式:
  - `one`: LV1の成功タイム配列（ミリ秒）
  - `two`: LV2の成功タイム配列（ミリ秒）
  - `three`: LV3の成功タイム配列（ミリ秒）
  - `four`: LV4の成功タイム配列（ミリ秒）
- 旧保存データに `three` / `four` がなくても空配列として扱う
- 各レベル最速5件のみ保持する
- 衝突したプレイは保存しない
- タイムは短い順に並べる
- 不正な保存値は読み飛ばし、ゲームを継続する
- 既存の他コンテンツのlocalStorageキーは変更しない
- サーバー送信は行わない

## 10. Scenario QA

### first use

レベル選択後、説明を読まなくても `おして すすむ / はなすと ストップ` とタイマーが見える。

期待: 長押しで動き、離すと停止し、タイマーが進む。

### direction

各レベルを開始して左右方向の車を見る。

期待: 車の移動方向と車絵文字の前後方向が一致する。

### incomplete action

1. 長押しする
2. 途中で指を離す
3. 再度長押しする

期待: 離した瞬間に停止し、再度押せば続きから進む。停止中もゲーム内タイムは進む。

### collision / feedback

車と同じ位置で前進する。

期待:
- 衝突した瞬間に移動と車の更新が止まる
- 今回タイムは表示するがハイスコア登録しない
- 失敗音が鳴る
- Vibration API対応端末では振動する
- 非対応環境でもエラーにならず結果画面へ進む

### success / high score

1. ゴールへ到達する
2. 同じレベルを複数回成功する

期待: 今回タイムを0.1秒単位で表示し、レベル別に速い順のベスト5だけが保存される。最速ならベスト更新表示が出る。

### randomness

同じレベルを複数回開始する。

期待: 車速・出現間隔・車種が毎回完全固定ではない。一方で定義した上下限を越えない。

### LV3 / LV4

LV3とLV4で、各車線を一つずつ越えていく。

期待:
- LV3は3車線、LV4は4車線が表示される
- 隣接車線で進行方向が交互になる
- 各車線で独立して車が出現する
- 途中の車線を越えてもゲーム状態とタイマーを維持する

### repeated input

長押し中に別の指で触る、素早く押す・離すを繰り返す。

期待: キャラクターが二重速度にならず、操作不能にならない。

### score compatibility

LV1/LV2だけの旧保存データを持つ状態で更新後に起動する。

期待: 旧ベストを維持し、LV3/LV4を空のランキングとして追加できる。他教材の記録を変更しない。

### accessibility / viewport

- 360x640
- 768x1024
- 200%文字拡大
- Space / Enter長押し
- 画面回転後

期待: LV1〜LV4選択、主要操作、タイマー、ベスト表示が利用可能でゲームを完了できる。
