# かずの ならび 仕様書

## 1. 概要

- 目的: 数の順序と一定間隔で増える規則を理解する
- 対象ユーザー: 10までの数を学び始めた幼児〜小学生
- contentId: `number-sequence`
- 公開URL: `/number-sequence`
- 学習経路: STEP 4

## 2. セッション

- 全レベル30秒固定
- 時間制限なしモードは設けない
- 30秒経過時に回答を停止し、結果画面へ移動する

## 3. 難易度

| レベル | 数の範囲 | 数列の長さ | 増え方 |
|---|---:|---:|---|
| やさしい | 1〜10 | 4 | 1ずつ |
| ふつう | 1〜20 | 4 | 1または2ずつ |
| むずかしい | 1〜100 | 5 | 2、5、10ずつ |

## 4. 操作

1. 難易度を選ぶ
2. 数列中の `❓` に入る数を3択から選ぶ
3. 正誤表示後、次の問題へ進む
4. 30秒後に得点、正解数、回答数を表示する

## 5. 得点

- やさしい: 基本10点
- ふつう: 基本20点
- むずかしい: 基本30点
- 連続正解時は2点ずつ加算する
- 不正解時はコンボを0へ戻す

## 6. 保存

- storage key: `number_sequence_v1_history`
- 保存項目: 日時、レベル、スコア、正解数、回答数
- 保持件数: 最新50件
- 全削除は確認ダイアログを必須とする

## 7. UI

- スマホ縦では難易度を1列、回答を3列で表示する
- 640px以上では難易度を3列で表示する
- 主要ボタンは44px以上のタップ領域を確保する
- 数列の欠けた箇所は `❓` と破線枠で示す
- 色だけで正誤を表現しない
- `prefers-reduced-motion` に追従する

## 8. 受け入れ条件

- [ ] 全レベルが30秒で終了する
- [ ] 時間制限なしモードが存在しない
- [ ] 各レベルの範囲と増え方が仕様どおりである
- [ ] 常に正解を含む重複なしの3択を表示する
- [ ] 正解・不正解後に次の問題へ進む
- [ ] 結果と履歴が保存される
- [ ] `/number-sequence` を直接開ける
- [ ] 一覧へ戻れる
